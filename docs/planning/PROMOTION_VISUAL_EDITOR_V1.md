# 홍보 글 시각 편집기 V1

상태: 확정 · 2026-11-14 사용자 승인: 브리핑한 글쓰기 구성을 그대로 제작.

## 목적과 업무 흐름

홍보직원·운영팀장·운영총괄이 ERP에서 문단, 소제목, 강조, 인용, 목록, 링크, 문단 사이 사진과 설명을 직접 편집한다. 작성 → 첨부 사진 선택·본문 삽입 → PC/모바일 본문 미리보기 → 임시저장/수정본 저장 → 기존 역할별 검토·승인·발행 순서를 유지한다. 글의 내용과 사진 공개 여부는 사람이 판단한다. 문맥을 AI가 자동 재작성하거나 신규 유료 서비스를 호출하지 않는다.

## 현재 범위

- Tiptap 시각 편집기를 기존 작성·보완·검토 수정·게시 후 본문 수정에 연결한다.
- 소제목/작은 소제목, 굵게, 인용, 글머리/번호 목록, 웹 링크, 실행 취소/다시 실행.
- 검증된 기존 압축·업로드(12장, 원본 15MB, 압축 1MB) 유지. 첨부된 사진을 원하는 문단에 삽입, 설명 입력, 문단·사진 위아래 이동, 본문에서 사진 제거.
- 목록 대표사진은 기존 hero_image_url로 별도 지정. 본문 배치와 독립적이다.
- 기존 public_body에 버전 표식과 편집기 문서를 함께 저장. 새 테이블/권한/RPC/migration 없음. 기존 revision/audit/승인선 재사용.
- 저장된 문서는 공개 브라우저와 Edge SSR, ERP 미리보기에서 동일한 안전 렌더러로 표시한다. 허용된 텍스트 구조만 렌더링하고 사진은 승인된 public_media의 영구 URL과 정확히 일치해야 한다.
- 기존 평문 글과 특정 기획기사 전용 표시 로직은 그대로 둔다. 기존 글을 열기만 해서는 내용을 변환·재저장하지 않는다. 서식 편집 이후부터 새 형식으로 저장한다.

## 예외와 경계

- 저장 실패 시 입력과 첨부 유지. 업로드 실패/인증 재시도는 기존 구현 사용.
- 기존 30,000자 저장 한도에는 문서 구조도 포함. 초과하면 명시적으로 저장 중단, 자동 잘라내기 금지.
- 손상된 새 형식은 원문 편집을 막고 안내. 기존 승인된 사진 외 외부 이미지 임베드는 허용하지 않는다.
- 일반 수정 요청의 자유 서술란은 글 편집기로 바꾸지 않는다.
- 게시 후 문구 수정 권한은 기존 첨부만 재배치할 수 있고 사진 업로드 권한을 추가하지 않는다.
- main 병합, 운영 DB 변경, 실사용 글 발행은 이번 개발 검수에서 제외한다. PR #673의 기획기사 고정/정렬 작업과 독립 브랜치다.

## 수용 검수

단위 검수: 문단·소제목·사진·설명 순서, 평문 보존, 저장 왕복, HTML/링크 주입 방지, 미승인 이미지 차단, 본문에서 제거한 사진 재출현 방지.
브라우저: 운영총괄 기준 및 운영팀장/홍보직원, 320/390/768/1440, 서식 작성·사진 삽입·설명·이동·취소·대표사진·미리보기·저장 실패·재열기. 합성 fixture RPC만 사용한다.
회귀: 공개 홈페이지, 플랫폼 정적 검사, Netlify 산출물, 기존 홍보 브라우저 검사.

## 후속 범위

협업 동시 편집, AI 자동 글 다듬기, 표/동영상 임베드, 문서 업로드 변환은 이번 V1에 포함하지 않는다.
