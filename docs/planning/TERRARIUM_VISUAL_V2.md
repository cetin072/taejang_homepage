## 사실·안전 경계
- 현재 활동: 태장 내부의 테라리움 제작 교육·식물 관리 활동.
- 외부 주문제작·키트·클래스·출강은 모두 준비 중이다. 문의 링크는 기존 회사 일반 문의이며 신규 예약/결제/견적 확정 기능이 아니다.
- 공개 시안 가격, 수업 정원, 고정 제작기간, 배송 보장, 전문자격·인증·납품실적을 임의로 게시하지 않는다.
- 일반 식물 관리 설명은 조건부 안내이며 모든 테라리움에 동일 주기/무관리/영구수명/공기정화·치료 효과를 주장하지 않는다.
- 기존 승인 WebP 사진은 참고 샘플로 유지. 새 SVG는 직접 작성한 콘셉트 일러스트이며 실제 직원 활동이나 납품 실적으로 소개하지 않는다.
- 신규 서버, DB, 런타임 의존성, 외부 서비스, 고객 개인정보 수집 없음. 회사 공통 헤더·푸터·메인·서비스 메뉴 소스 변경 없음.
