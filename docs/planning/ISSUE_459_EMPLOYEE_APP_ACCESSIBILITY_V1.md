## 2026-10-19 추가 디자인 마감 — 확정

사용자 추가 지시로260ms 회전을420ms(210+210)로 감속한다. 성공/실패/동작 줄이기/반복 방지 조건은 유지한다. 버튼 아래 기록은 연한 보조 칩으로 표시하고, 출근 전에는 빈 칩을 만들지 않으며 출근만 있으면 출근 칩만, 퇴근 후에는 두 칩을 표시한다. 예외 대기·반려·보정 등 기존 서버 상태는 해당 칩의 텍스트/접근성 레이블에 남긴다. 칩은 자동 줄바꿈·높이 확장을 허용하고 글자 확대 제한을 두지 않는다. 가상 내역은 실제 기록 아님 경계를 유지한다. 서버 계약/기록 로직/신규 기능/권한 변경 없음.
