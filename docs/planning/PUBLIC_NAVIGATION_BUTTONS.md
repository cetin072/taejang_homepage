# 공개 홈페이지 이동 버튼 통일

2026-11-14 사용자 확정: ‘하는 일’의 환경정비 활동 보기 버튼을 기준으로 공개 홈페이지 전반에 적용한다.

- 독립된 상세페이지·목록·이전 페이지 이동은 녹색 1px 테두리, 흰 배경, 8px 모서리, 최소 48px 높이로 통일한다. 너비는 내용에 맞추며 좁은 화면에서는 문구를 줄바꿈한다.
- 기존 페이지 이동은 a/href를 유지한다. 페이지 이동 →, 외부 이동 ↗, 같은 페이지 이동 ↓, 뒤로 이동 ←를 표시한다.
- 핵심 문의·신청과 메인 히어로의 우선순위는 유지한다. 기존 버튼은 모서리·최소 높이·hover 움직임만 공통 정리한다.
- 메뉴·푸터·본문 출처·문장 속 링크·공식 스토어 배지·이미지 원본 링크와 전체가 클릭되는 카드는 별도 박스로 만들지 않는다.
- 공통 styles.css와 명시적 page-link 클래스를 재사용한다. 내부 ERP·직원앱에는 적용하지 않는다. 자동 생성되는 활동 상세페이지와 홍보글 목록 복귀 링크도 포함한다.
- 확인: 공개 회귀/빌드, 320·390·768·1440px 버튼 넘침·높이·테두리·포커스, 기존 href 보존 및 JS 없이 이동, 대표 페이지 시각 확인.
- 구현 승인 범위이며 main 병합 및 운영 배포는 별도 요청 전 실행하지 않는다.
