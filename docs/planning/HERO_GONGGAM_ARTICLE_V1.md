# 경남공감 기사 히어로 소개

2026-10-26 사용자 승인 범위: 첨부 JPEG를 공개 홈페이지 첫 히어로 슬라이드에 사용하고 기사 링크·HTML 캡션을 추가한다. 코드·최적화 자산·검증·브랜치 업로드·Draft PR·개발 Preview까지이며 Ready·main 병합·Production 배포는 별도 승인 대기다. PR #530·#531과 혼합하지 않는다.

## 구현

- 첫 슬라이드: 사용자 제공 단체사진. 기존 두 영상 `FbEOcteBSJ4` → `8x7yg5YBK9g`는 뒤에 같은 순서로 유지한다. 자동 전환 없음.
- 제목: **민·관이 함께 만든 장애인 동행 일자리 1호점 태장(주)** / 출처: **경남공감**. 사진과 캡션은 하나의 새 탭 링크이며 새 탭 안내·noopener noreferrer·alt·초점을 제공한다.
- 원문: https://www.gyeongnam.go.kr/gonggam/index.gyeong?menuCd=DOM_000001514000000000&ggSeq=41900&gg_depth1=12&gg_depth2=02&ggVolumeAndNewOldStatus=163%3ANEW#snsClose
- 공식 페이지 조회 실패 및 검색 결과 부재로 호수·발행월은 미확인이다. URL 숫자를 근거로 표기하지 않는다. 제목·출처·사진 사용은 이번 사용자 지시를 기준으로 하며 기사 본문을 재게시하지 않는다.
- 첨부 픽셀 2048×1035 확인. 인물·내용·비율을 바꾸지 않은 로컬 WebP 2048px/960px를 사용한다. 원본은 덮어쓰지 않고 EXIF를 복사하지 않는다. 외부 이미지 핫링크와 이미지 생성 없음.
- 자연 높이의 사진·캡션이 슬라이더 높이를 정한다. 비활성 기사도 `visibility:hidden`으로 공간만 유지해 영상 선택 시 높이 점프를 막는다. hidden/aria-hidden 및 visibility로 비활성 링크의 접근·초점을 차단하고, 기사 내부에서 방향키로 전환하면 슬라이더로 초점을 옮긴다.

## 검증 경계

`tests/hero-article-browser.mjs`: 실제 로컬/Preview 자산을 320·390·1440px에서 검증한다. 사진 비율·decode, 캡션·가로 넘침, 사진/제목 클릭, 높이 유지, 방향키·swipe, 영상 iframe 생성·제거·poster 복원을 확인한다. 외부 기사와 YouTube iframe 응답은 격리한다. 실제 기사 서버 응답 및 YouTube 스트리밍·오디오 재생 성공을 주장하지 않는다. JS 미실행 시 첫 사진·기사 링크가 남는지도 확인한다.

공개 회귀·빌드와 최신 HEAD CI·개발 Preview 상태는 PR에 누적한다. 운영 DB·계정·권한·보호 규칙·배포 설정은 변경하지 않는다. 최신 main의 72시간 정기 배포 및 독립 수동 배포 경로를 유지한다. 고정 사용자 QA는 다른 작업을 덮어쓰지 않는다.
