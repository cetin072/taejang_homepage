# 기본 인사정보 주소·재택근무 간소화

2026-11-16 사용자 확정: 위도·경도 입력 제거. 선택 질문에 **위치 확인 없이 허용** 응답. 주소와 재택근무 체크는 별도 편집창 없이 기본 인사정보 폼에서 수정·삭제·저장한다.

- 운영총괄이 기존 권한으로 주소와 재택근무 여부를 설정한다. 직원 자기승인은 허용하지 않는다.
- 단일 RPC가 기존 직원정보 수정과 주소/재택 설정을 원자적으로 수행한다. 실패하면 둘 다 이전 상태를 유지한다.
- 주소를 지우면 재택 체크도 해제한다. 재택 사용에는 주소가 필요하지만 주소를 좌표로 변환하거나 외부에 전달하지 않는다.
- 명시적으로 새 재택 설정을 저장한 근태 대상 재직 직원만 GPS 확인 없이 출퇴근한다. 기존 GPS 승인은 관리자가 수정하기 전까지 기존 방식으로 유지한다.
- 웹·직원앱은 매 시도 서버 상태를 재조회한다. 서버가 최종 판단한다. 일반 직원 위치 검증, 근무일·휴가·출근 가능 시간, 선행 출근·중복·권한 검증은 유지한다.
- 원본 근태에 remote_work를 기록하고 가짜 위치를 저장하지 않는다.
- 모바일 변경은 새 앱 빌드가 필요하다. 기존 설치 앱은 위치 권한 요청을 계속할 수 있다. Play 제출은 별도이다.

검증: 기존 GPS pgTAP에 위치 없는 재택 기록/해제/일반 직원 차단/통합 저장 롤백을 추가한다. 기본 인사정보 PC·모바일 브라우저 검사는 주소 수정·삭제·공동 저장을 검증한다. 모바일 실컴포넌트 검사는 서버 상태 재조회·GPS 생략·해제 후 위치 요청을 검증한다.
