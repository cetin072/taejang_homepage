# 오시는 길 개선 — 2026-11-14 확정

사용자는 기존 검수안을 승인하고 밋밋한 화면을 보완할 이미지 추가를 요청했다. ‘만 평’은 넓은 농장이라는 인상을 주는 홍보 요소이므로 축소하지 않는다.

- 구현: 짧은 도입, 본점 주소·호실·지도 버튼 우선 배치, 중복 주소 항목과 장식 핀 제거.
- 구현: 전체 주소 복사, 성공/실패 알림. JS 실패 시에도 주소·지도·연락처 유지.
- 구현: 약 1만 평을 큰 글자로 강조하고 진전면 위치와 구분. 농장 소개·문의 링크 유지.
- 구현: 본점에는 기존 contact-illustration.webp 재사용. 농장에는 새 수채화 컨셉 이미지를 사용하고 캡션으로 명시. 실제 건물·농장 사진, 상세 주소·좌표, 예약 기능은 추가하지 않는다.
- 승인 범위: 개발·검수. main 병합과 운영 배포는 별도.

## 이미지 출처
