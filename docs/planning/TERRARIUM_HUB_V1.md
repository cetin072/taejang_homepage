# 태장 테라리움 기본 허브 V1 — 2026-11-11

## 사용자 요청과 경계
- 태장 메인의 테라리움은 현재 운영 4개 사업 중 하나. 사업 기본 랜딩페이지까지 공개한다.
- 실제 진행하는 테라리움 제작 교육·식물 관리 활동과 재료 이해, 상품 개발 방향을 설명한다.
- 주문제작 및 DIY 키트는 준비 중인 별도 서비스. 준비가 완료되면 이 기본 랜딩에서 각각 상세 페이지로 연결한다.
- 기존 주문제작 초안 PR #642는 보존하되 지금 공개하지 않는다. 원데이·정기 클래스도 현재 확정 모집 중인 것으로 소개하지 않는다.

## 정적 페이지 구성
- terrarium.html : 메인 비주얼 → 현재 교육과 식물 관리 → 참고 샘플 갤러리 → 주문제작·DIY 키트 준비 중 → 회사 문의
- assets/css/terrarium.css : 기존 태장 홈페이지 글꼴·헤더·푸터를 활용한 반응형 페이지 디자인
- index.html / business.html : 기존 운영 중 사업 카드에서 이 기본 랜딩으로 연결
- resources.html : 기존 테라리움 주문제작 준비 중 비클릭 카드를 '태장 테라리움 / 활동 소개' 활성 카드로 교체. 태장 업무수첩 준비 중 카드는 그대로 보존
- sitemap.xml, Netlify publish 파일 목록에 공개 정적 페이지 추가

## 기존 사진과 사실 경계
- assets/images/terrarium 폴더에 이미 공개되어 있던 참고 샘플 이미지만 사용한다.
- 사진을 태장 고객 주문제작 완료품, 태장 직접 생산 실적, 납품 성과로 소개하지 않는다.
- 실제 교육 및 완성품 사진을 추가로 전달받으면 원본을 보존하고 용량을 줄여 기존 이미지를 교체한다.
- 맞춤 주문제작의 가격·제작기간·배송·취소·결제 조건은 미확정. 기본 허브에서 구매나 예약을 받지 않는다.
- 문의는 기존 태장 협력·문의 페이지 및 회사 이메일로 연결. 신규 DB/외부 서비스/폼 수집 없음.

## 향후 상품 연결 방식
1. 주문제작 상세: 사용자 승인된 작품 사진·견적 조건·제작·배송 범위가 준비되면 주문제작 타일을 기존 독립 초안 페이지(예: terrarium-custom.html)로 연결.
2. DIY 키트: 상품 구성·안내·가격·배송 가능 조건이 확정되면 향후 별도 상품 상세 페이지로 연결.
3. 클래스: 원데이·정기 모집 조건이 확인되면 공지나 전용 안내에 링크. 오늘은 준비 방향만 안내.
