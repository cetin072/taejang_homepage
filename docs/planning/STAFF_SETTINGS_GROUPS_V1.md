# 직원앱 설정 카테고리 정리 — 2026-11-09

업무수첩 설정 정리와 같은 사용자 요청에 따라, 직원앱의 설정 항목도 카테고리별 카드로 묶는다. 업무수첩과의 런타임 의존은 만들지 않고 작은 그룹/행 UI 패턴만 직원앱 파일에 독립 적용한다.

| 순서 | 블록 | 항목 |
|---|---|---|
| 1 | 알림 | 공지 알림 설정 (로그인 시) |
| 2 | 앱 정보 | 업데이트·패치노트, 앱 정보와 연결 진단, 버전, QA 구분 |
| 3 | 개인정보 안내 | 개인정보처리방침, 계정 삭제 요청 |
| 4 | 계정 | 직원 이름, 내 정보 (로그인 시), 로그아웃 |

각 블록은 제목과 하나의 둥근 카드로 구분한다. 반복 설명을 줄이고 버튼은 56px 이상의 터치 영역을 유지한다. 직원앱의 녹색 계열, 기존 정책 링크·공지 알림 등록·내 정보·로그아웃 동작 및 로그인 여부에 따른 노출은 보존한다. 사용자 요청에 따라 기존 개인정보 푸터는 계정 앞의 독립 블록으로 이동하고 로그아웃을 맨 아래에 둔다.

이 변경은 설정 UI에 한정한다. 인증·권한·근태·데이터·빌드 설정은 변경하지 않는다. Draft PR로 준비하며 main 병합·운영 배포·Play 제출·새 APK 생성은 별도다. TypeScript, 모바일 회귀검사와 Android Metro bundle로 검증한다. 화면 캡처용 로컬 Chromium은 환경 socket 제한으로 실행되지 않아 실제 기기 화면 검수는 남아 있다.
