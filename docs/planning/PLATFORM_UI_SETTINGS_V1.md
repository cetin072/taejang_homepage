# 태장 플랫폼 UI 설정 V1

상태: 확정
관련 Issue: #323

## 목적

태장 업무플랫폼의 메뉴와 대시보드를 코드 수정 없이 운영·개인화할 수 있도록 한다.

## 1. 사이드바

- 메뉴는 canonical menu key를 가진 단일 registry에서 관리한다.
- 같은 기능을 여러 모듈이 삽입해도 같은 menu key는 하나만 남긴다.
- 운영총괄은 설정 화면에서 직책·역할별 표시 메뉴를 체크박스로 켜고 끌 수 있다.
- 메뉴 표시 여부는 기능 권한을 부여하지 않는다.
- 실제 접근은 capability, RPC, RLS가 최종 결정한다.

## 2. 개인 사이드바 설정

- 데스크톱 기본값은 펼침이다.
- 사용자는 자기 계정에서 접기/펼치기를 저장할 수 있다.
- 모바일 drawer 동작은 기존대로 유지한다.

## 3. 대시보드

- 사용자는 대시보드 수정 모드에서 카드를 드래그해 순서를 바꿀 수 있다.
- 마우스 드래그 외에 앞/뒤 이동 버튼을 제공한다.
- 개인별·역할별 순서를 저장한다.
- 기본 배치로 초기화할 수 있다.

## 4. 지원사업

- 지원사업 레이더: app/index.html?support=radar
- 기업 프로필: app/index.html?support=profile
- 기존처럼 사이드바 안에서 별도 그룹을 반복 주입하지 않는다.
- 기존 데이터/RPC/권한 로직은 그대로 사용한다.

## 5. 데이터 분리

- role_navigation_visibility: 운영총괄이 관리하는 직책별 메뉴 표시 설정
- profile_ui_preferences: 개인 사이드바 상태와 대시보드 카드 순서

이 두 설정은 권한 부여 데이터와 분리한다.
