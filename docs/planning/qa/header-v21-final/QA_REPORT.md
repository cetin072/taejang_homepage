## V2.1 대조

호스티드 검수에서 Netlify가 HTML 링크를 /about 등 clean URL로 변환함을 확인했다. 정적 순서는 의미상 동일하게 비교하고 site.js의 현재 페이지/대상 정규화도 모든 공개 clean URL에 맞췄다. 임직원 경로와 기존 표시 게이트는 유지하며 DOM 순서를 바꾸지 않는다.

HERO5.2초와 기존 SVG 인계, 카드 본체가 보인 후 Before2초→회전1초→After 정지, 이탈 pause/재진입 resume, 수동 양면 보기를 유지했다. 이번 후속에서 employee-app-motion.js/employee-app.css·랜딩 본문은 변경하지 않았다. 원래 날짜·문장·개선 방향·설치/계정 담당자 문의·정책 링크·로그인 화면의 랜딩 안내 보존.

**원래 랜딩에 공개 설치 링크는 없다.** 모바일 내부 Play Store 상수만으로 공개 설치 가능 여부를 확정하지 않고 새 설치 버튼·APK를 넣지 않았다. 앱·DB·Auth/RLS·로그인 처리·근태·공지 로직 무변경.
