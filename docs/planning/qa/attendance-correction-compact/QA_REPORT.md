## 실제 Chrome 합성 검증

tests/attendance-correction-browser.mjs는 실제 staff/dashboard/attendance CSS와 실제 근태 보정 JS를 사용한다. RPC만 합성 직원 24명으로 대체하며 실제 인증·데이터 저장 검증으로 기록하지 않는다.

| 폭×높이 | 이전 카드 높이 | 이후 카드 높이 | 온전히 보이는 직원 이전→이후 |
| --- | ---: | ---: | ---: |
| 1440×1000 | 284px | 134px | 3→6 |
| 768×1000 | 301px | 134px | 3→7 |
| 390×1000 | 433px | 287px | 1→2 |
| 320×1000 | 454px | 287px | 1→2 |

동일한 합성 정보/기존 이력에서 첫 카드가 보이는 위치를 맞추고 PC 고정 상단바에 가린 카드는 제외했다. 직원별 사유·브라우저 글자 크기에 따라 밀도는 달라진다.

4개 폭 모두 PASS:
- 같은 날짜 3명 연속 시간 정정, PC 독립 작업영역·모바일 문서 스크롤 오차 3px 미만.
- 수정하지 않은 카드 DOM 동일성 및 펼친 이력 보존, 수정 카드의 펼친 이력 보존.
- dialog 저장 실패 후 시·분·사유 보존 및 재시도.
- 누락 시간 추가의 선택 사유(null) 계약 및 무효 처리 후 유효 액션 갱신.
- 저장 성공 후 조회 실패를 별도 안내하고 해당 카드의 중복 쓰기 방지.
- 날짜 변경의 이전 조회 응답 무시, 권한 없는 진입 RPC 0.
- 키보드 native summary 펼침, 가로 넘침·카드 내부 넘침 0.
- 실제 PC/모바일 캡처 가독성 수동 확인.

기존 검사 PASS: 플랫폼 정적 578건, 급여 회귀 524건, 기존 출근부 PC/모바일(월별/Excel/필터/실패 보존), 관련 계약 29건, build:netlify, diff --check.
