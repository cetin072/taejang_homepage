# 공개 자료실 V1

## 확정과 목적

2026-11-03 사용자 승인: 상단 직원앱 항목을 자료실로 바꾸고 협력·문의 다음에 배치한다. 앱과 회사 자료를 카드에서 찾아 각 안내 페이지로 이동한다. 공개 정보 탐색을 단순화하며 기존 직원 앱과 임직원 업무 플랫폼의 주소·권한을 유지한다.

## 범위와 상태

- 자료실: 기존 resources.html을 정적 카드 목록으로 확장한다. PC·모바일 모두 협력·문의 → 자료실 → 임직원 순서다. JavaScript 없이도 링크·상태가 보인다.
- 직원 앱: 기존 employee-app.html로 연결한다. 기존 안내 내용과 주소를 유지하며 자료실로 돌아가는 링크를 제공한다.
- 태장 업무수첩: 태장 전용 공개본 준비 전까지 준비 중으로 표시한다. 다른 프로젝트의 업무수첩이나 QA APK로 연결하지 않는다.
- 회사소개서: 2026-11-03 사용자 수용 검수에서 카드 자체 삭제로 확정했다. 승인된 공개본이 완성되기 전까지 카드와 메타데이터에 표시하지 않는다. 향후 공개본 준비 후 카드와 실제 안내·다운로드를 추가한다.
- 임직원: 기존 로그인 입구와 접근 제어를 유지한다.

## 구현과 검수

정적 HTML/CSS와 기존 메뉴 스크립트를 재사용한다. 새 서비스·라이브러리·API·DB·권한 변경은 없다. 생성 활동 페이지도 기존 헤더 생성 경로를 통해 동일 메뉴를 받는다.

검수: 메뉴 순서·중복·직원 앱 이동·되돌아오기·준비 중 카드의 비클릭 상태·키보드 포커스·모바일 메뉴·가로 넘침·JS 실패 시 정적 안내·생성 산출물을 확인한다.

후속: 태장 전용 업무수첩과 승인 회사소개서 공개 준비가 끝나면 각각 실제 안내·다운로드를 연결한다. 이번에는 해당 페이지와 파일을 임의 제작하지 않는다. main 병합과 운영 배포는 별도 승인 범위다.

## 2026-11-09 변경: 서비스·상품

사용자 승인으로 공개 메뉴와 허브 명칭을 ‘서비스·상품’으로 변경한다. 기존 resources.html 주소와 메뉴 순서는 유지한다.

- 태장 출근앱: 직원 출퇴근·근태관리 안내이며 기존 employee-app.html로 연결한다.
- 뉴질랜드 천일염: 10kg 상품 소개를 준비하는 비클릭 ‘준비 중’ 카드로 표시한다. 랜딩 검수·공개 승인 전에는 연결하지 않는다.
- 업무수첩: 공개 허브에서 카드와 소개를 숨긴다. 기존 페이지·개발 코드·기존 이용자와 테스터의 접근은 삭제하거나 변경하지 않는다.
- 회사소개서 비노출과 임직원 접근은 이전 결정을 유지한다. 천일염 랜딩 개발은 별도 범위이며 이번 변경으로 공개하지 않는다.

검수에는 PC·모바일 및 JavaScript 비활성 상태의 메뉴 명칭, 두 카드만 표시, 업무수첩 비노출, 천일염의 준비 중·비클릭 상태를 추가한다. 운영 즉시 배포는 하지 않는다.


## 2026-11-10 변경: 천일염 판매 안내·업무수첩 재노출

사용자 최신 요청으로 위 2026-11-09 카드 상태 결정을 변경한다.

- 뉴질랜드 천일염: ‘준비 중’을 제거하고 ‘판매 중’ 카드로 기존 `new-zealand-salt.html` 상품·간편 문의 페이지에 연결한다. 확정 규격 10kg·25kg을 안내하며 가격·결제 기능을 추가하지 않는다.
- 태장 업무수첩: 카드와 소개를 다시 노출하되 ‘준비 중’ 비클릭 상태로 둔다. 실제 업무수첩·테스트 앱에 연결하지 않는다.
- 태장 출근앱, 서비스·상품 메뉴명·주소·순서, 회사소개서 비노출은 유지한다. 기존 천일염 랜딩의 검색 설정·문의 폼 및 운영 배포 정책은 변경하지 않는다.
- 정적 회귀 및 PC·모바일 1440/390/320px, JS on/off 브라우저 검사에 카드 3개·판매/준비 상태·출근앱 왕복·상품 안내/문의 이동·뒤로가기를 반영한다.
- 구현과 병합 승인을 구분하며 운영 즉시 배포하지 않는다. 기존 72시간 정기 배포 정책 유지.
