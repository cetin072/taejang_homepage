# 역할별 메뉴·대시보드 우선순위 V1

상태: 확정
확정일: 2026-09-04
관련 Issue: #103

## 1. 목적

태장 업무앱의 사이드바와 대시보드를 직책별 실제 업무 우선순위에 맞게 정리한다. 직급이 높아질수록 열람 범위는 넓어지되 첫 화면은 더 압축한다.

## 2. 공통 확정 원칙

- 상단 바와 본문에 같은 `OO 대시보드` 제목을 중복 표시하지 않는다.
- 상단 바에는 현재 역할/위치를 짧게 표시하고 본문 화면 제목은 한 번만 표시한다.
- 대시보드는 오늘 처리할 일과 중요한 상태 중심으로 유지한다.
- 작업 매뉴얼은 대시보드 카드와 빠른 이동에서 제거하고 사이드바에서만 접근한다.
- 준비 중 기능 카드는 대시보드에서 제거한다.
- 실제 미완성 기능은 `· 점검중`을 붙여 사이드바 최하단으로 이동한다.
- 현재 확인된 점검중 기능은 `신규 사업 기획`이다.
- 점검중 메뉴는 일반 메뉴보다 낮은 강조도로 보이되 가독성을 해치지 않는다.
- hover/active/focus-visible 상태에서 메뉴 글자가 배경에 묻히지 않게 대비를 고정한다.
- 모바일에서도 중요 메뉴가 먼저 보이고 점검중 메뉴가 마지막에 온다.
- 아래 메뉴표는 **해당 역할에 이미 허용되어 실제 기능이 존재하는 메뉴의 최종 우선순위**를 뜻한다.
- 이번 V1은 메뉴 정리 작업이므로 새로운 Auth/RLS/업무 권한을 부여하지 않는다. 현재 권한이 없는 메뉴는 화면에 억지로 만들지 않으며, 권한 확대는 별도 기획·승인 후 진행한다.
- 태장 고유 녹색은 유지하되 지나치게 단조롭지 않도록 골드·블루·코랄·민트 계열을 보조색으로 제한적으로 사용한다.
- 보조색은 카드 구분, 상태 강조, 현재 선택 메뉴, 공식 외부채널 구분에 사용하고 업무 의미를 혼동할 정도로 과도하게 사용하지 않는다.

## 4. 공식 외부채널 바로가기

홍보직원, 운영팀장, 운영총괄에게만 다음 공식 채널 바로가기를 제공한다.

- 공식 블로그: `https://blog.naver.com/taejang-official`
- 공식 유튜브: `https://youtube.com/@taejangofficial`

두 링크 모두 새 탭에서 열고 `noopener noreferrer`를 적용한다. 이 링크는 공개 홈페이지의 공식 조직 구조화 데이터에 등록된 채널 주소와 동일하게 유지한다.

- 실제 미완성 기능을 정상 카드처럼 노출하는 요소

## 7. 메뉴 구현 구조

- 역할별 최종 우선순위는 중앙 navigation priority registry가 결정한다.
- 기능 모듈이 메뉴 항목을 추가하더라도 최종 DOM 순서는 중앙 정렬기가 역할별 우선순위대로 고정한다.
- `status=checking` 또는 `· 점검중` 항목은 항상 마지막으로 이동한다.
- 기존 기능별 권한 판정과 클릭 동작은 유지한다.
- 중앙 정렬기는 기존 메뉴를 재배치할 뿐, 권한이 없는 기능을 새로 생성하지 않는다.
- 공식 채널 링크는 허용 역할에서만 생성하며 내부 업무 권한과 무관한 외부 바로가기다.

## 8. 디자인 기준

- 태장 메인 녹색은 브랜드 기준색으로 유지한다.
- 골드는 선택 상태와 중요한 시각 포인트, 블루는 정보성 카드, 코랄은 주의를 끄는 보조 카드, 민트는 안정적인 배경 포인트로 제한 사용한다.
- 카드마다 상단에 얇은 포인트 컬러를 적용해 업무 묶음을 빠르게 구분할 수 있게 한다.
- 대시보드 소개 영역은 흰색 기반에 녹색 좌측선과 따뜻한 베이지 그라데이션을 사용한다.
- 공식 블로그와 유튜브는 전체 메뉴 색체계를 깨지 않으면서 작은 채널 포인트색으로 구분한다.
- 색상만으로 의미를 전달하지 않고 텍스트 라벨을 항상 유지한다.

## 9. 검수 기준

- 각 역할에서 실제 표시되는 메뉴가 해당 역할의 우선순위 순서와 일치한다.
- 모든 기존 메뉴 클릭이 정상 패널/워크스페이스를 연다.
- 대시보드 복귀가 정상이다.
- 운영총괄 대시보드 제목이 중복되지 않는다.
- 작업 매뉴얼/준비중 카드가 대시보드에서 사라진다.
- 점검중 메뉴가 항상 최하단이고 보조색으로 표시된다.
- active/hover/focus-visible에서 글자 대비가 유지된다.
- 모바일 사이드바 스크롤과 터치 타깃이 정상이다.
- 일반직원 공통 홈과 역할 시뮬레이션에 회귀가 없다.
- 이번 PR 때문에 새 역할 권한이 생기지 않는다.
- 홍보직원·운영팀장·운영총괄에서 공식 블로그/유튜브가 정확한 주소로 새 탭에서 열린다.
- 공식 채널 링크가 일반직원·부서팀장·현장반장·대표이사·시스템관리자에게 불필요하게 노출되지 않는다.
- 추가 보조색이 모바일 가독성이나 텍스트 대비를 해치지 않는다.

## 10. 이번 범위에서 변경하지 않는 것

- Auth/RLS/권한 의미
- 직원 마스터 데이터 구조
- GPS 출퇴근 서버 로직
- 홍보 승인 흐름
- 홈페이지 발행/직접수정 승인 규칙

## 결정 이력

- 2026-09-04: 사용자 승인으로 역할별 메뉴 우선순위, 대시보드 정리, 점검중 최하단 배치와 색상 개선을 확정함.
- 2026-09-04: 메뉴 우선순위 정리는 기존 권한 범위 안에서만 적용하며 새로운 관리 권한은 이 V1에서 생성하지 않는 것으로 명확화함.
- 2026-09-04: 태장 녹색을 유지하면서 보조색을 추가하고, 홍보직원·운영팀장·운영총괄에 공식 블로그/유튜브 바로가기를 제공하기로 확정함.
