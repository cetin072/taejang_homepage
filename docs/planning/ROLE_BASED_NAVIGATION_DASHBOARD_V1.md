# 역할별 메뉴·대시보드 우선순위 V1

상태: 확정
확정일: 2026-09-04
관련 Issue: #103

## 1. 목적

태장 업무앱의 사이드바와 대시보드를 직책별 실제 업무 우선순위에 맞게 정리한다. 직급이 높아질수록 열람 범위는 넓어지되 첫 화면은 더 압축한다.

## 2. 공통 확정 원칙

- 상단 바와 본문에 같은 `OO 대시보드` 제목을 중복 표시하지 않는다.
- 상단 바에는 현재 역할/위치를 짧게 표시하고 본문 화면 제목은 한 번만 표시한다.
- 대시보드는 오늘 처리할 일과 중요한 상태 중심으로 유지한다.
- 작업 매뉴얼은 대시보드 카드와 빠른 이동에서 제거하고 사이드바에서만 접근한다.
- 준비 중 기능 카드는 대시보드에서 제거한다.
- 실제 미완성 기능은 `· 점검중`을 붙여 사이드바 최하단으로 이동한다.
- 현재 확인된 점검중 기능은 `신규 사업 기획`이다.
- 점검중 메뉴는 일반 메뉴보다 낮은 강조도로 보이되 가독성을 해치지 않는다.
- hover/active/focus-visible 상태에서 메뉴 글자가 배경에 묻히지 않게 대비를 고정한다.
- 모바일에서도 중요 메뉴가 먼저 보이고 점검중 메뉴가 마지막에 온다.

## 5. 대시보드에서 제거

- 작업 매뉴얼 카드
- 작업 매뉴얼 빠른 이동 버튼
- 준비 중 카드
- 신규 사업 기획 빠른 이동 버튼
- 실제 미완성 기능을 정상 카드처럼 노출하는 요소

## 6. 메뉴 구현 구조

- 역할별 최종 우선순위는 중앙 navigation priority registry가 결정한다.
- 기능 모듈이 메뉴 항목을 추가하더라도 최종 DOM 순서는 중앙 정렬기가 역할별 우선순위대로 고정한다.
- `status=checking` 또는 `· 점검중` 항목은 항상 마지막으로 이동한다.
- 기존 기능별 권한 판정과 클릭 동작은 유지한다.

## 7. 검수 기준

- 각 역할별 메뉴 순서가 확정안과 일치한다.
- 모든 기존 메뉴 클릭이 정상 패널/워크스페이스를 연다.
- 대시보드 복귀가 정상이다.
- 운영총괄 대시보드 제목이 중복되지 않는다.
- 작업 매뉴얼/준비중 카드가 대시보드에서 사라진다.
- 점검중 메뉴가 항상 최하단이고 보조색으로 표시된다.
- active/hover/focus-visible에서 글자 대비가 유지된다.
- 모바일 사이드바 스크롤과 터치 타깃이 정상이다.
- 일반직원 공통 홈과 역할 시뮬레이션에 회귀가 없다.

## 8. 이번 범위에서 변경하지 않는 것

- Auth/RLS/권한 의미
- 직원 마스터 데이터 구조
- GPS 출퇴근 서버 로직
- 홍보 승인 흐름
- 홈페이지 발행/직접수정 승인 규칙
