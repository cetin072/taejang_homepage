# 메인 참여기업·기관과 문의 팝업 V1

상태: 2026-11-10 사용자 기획 승인 및 현재 공개 명단 지정.

## 확정 범위
- 협력 분야 → 함께하는 기업·기관 → 문의하기 버튼 → 푸터 흐름으로 정리.
- 모기업 4개사: 범한메카텍, 삼현, 청우비제이, 현대비앤지스틸.
- 추가 5곳: 경상남도, 미담농원, 아름다운학교, 미래진흥원, 학사모.
- 류진농원과 그 외 기업·기관은 추후 추가. 현재 명단에 포함하지 않는다.
- 공동출자 참여기업과 사업·농업·지역 협력을 구분한다. 경상남도는 동행일자리 1호점 사업 연계로 설명하며 출자·보증·후원을 주장하지 않는다.
- 법인 전체 명칭, 협약 상태·날짜·효과를 추정하지 않고 사용자가 확인한 이름 그대로 표시한다.
- 공식 로고 원본이 모두 준비되지 않았으므로 현재는 동일한 텍스트 명칭 스타일로 표시한다. 임의 로고 생성·기존 현판 글자 재구성 없음. 이후 확인된 로고로 교체할 수 있다.
- 인증·현판 소개는 certifications.html로 연결한다.

## 문의 흐름과 구현
기존 Netlify form 이름/POST action/필드/동의/스팸 방지/감사 페이지를 유지하며 정적 HTML의 native dialog 안에 재사용한다. 새 접수 서버·메일 서비스·DB는 없다. 메인에 봉투 아이콘과 문의하기 표시 하나를 둔다. JS 실패·미지원이면 같은 링크가 기존 partnership.html#contact로 이동한다. 기존 index.html#contact 진입은 JS가 있으면 팝업을 열고 없으면 문의 링크 영역으로 이동한다.

닫기·Esc·배경 클릭, 초점 제한·열었던 링크로 초점 복귀, 모바일 내부 스크롤과 배경 스크롤 잠금을 제공한다. 닫거나 재오픈해도 같은 DOM의 입력·선택·동의는 초기화하지 않는다. 새로고침 후 개인정보를 브라우저 저장소에 보관하지 않는다. 이메일·오시는 길은 팝업과 기존 푸터에서 접근한다. 문의 전송은 기존 브라우저 기본 POST 동작이다.

## 검수
확정 9개 명칭·류진 제외·관계 구분, JS off 정적 명단과 문의 fallback, 320/390/1440px 넘침, 열기/닫기/재오픈·입력 보존·Esc·키보드 초점·배경 클릭·깊은 링크, 필수 입력 유효성 및 합성 POST payload(실제 접수 금지), 공개 회귀·Netlify 빌드를 확인한다. 사용자 승인 전 main/Production/운영 DB 변경 없음.
