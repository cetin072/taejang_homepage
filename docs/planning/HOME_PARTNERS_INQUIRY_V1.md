# 메인 참여기업·기관과 문의 팝업 V1

상태: 2026-11-10 사용자 기획 승인 및 현재 공개 명단 지정.

## 확정 범위
- 협력 분야 → 함께하는 기업·기관 → 문의하기 버튼 → 푸터 흐름으로 정리.
- 모기업 4개사: 범한메카텍, 삼현, 청우비제이, 현대비앤지스틸.
- 추가 5곳: 경상남도, 미담농원, 아름다운학교, 미래진흥원, 학사모.
- 류진농원과 그 외 기업·기관은 추후 추가. 현재 명단에 포함하지 않는다.
- 공동출자 참여기업과 사업·농업·지역 협력을 구분한다. 경상남도는 동행일자리 1호점 사업 연계로 설명하며 출자·보증·후원을 주장하지 않는다.
- 법인 전체 명칭, 협약 상태·날짜·효과를 추정하지 않고 사용자가 확인한 이름 그대로 표시한다.
- 공식 로고 원본이 모두 준비되지 않았으므로 현재는 동일한 텍스트 명칭 스타일로 표시한다. 임의 로고 생성·기존 현판 글자 재구성 없음. 이후 확인된 로고로 교체할 수 있다.
- 인증·현판 소개는 certifications.html로 연결한다.

## 문의 흐름과 구현
기존 Netlify form 이름/POST action/필드/동의/스팸 방지/감사 페이지를 유지하며 정적 HTML의 native dialog 안에 재사용한다. 새 접수 서버·메일 서비스·DB는 없다. 메인에 봉투 아이콘과 문의하기 표시 하나를 둔다. JS 실패·미지원이면 같은 링크가 기존 partnership.html#contact로 이동한다. 기존 index.html#contact 진입은 JS가 있으면 팝업을 열고 없으면 문의 링크 영역으로 이동한다.

닫기·Esc·배경 클릭, 초점 제한·열었던 링크로 초점 복귀, 모바일 내부 스크롤과 배경 스크롤 잠금을 제공한다. 닫거나 재오픈해도 같은 DOM의 입력·선택·동의는 초기화하지 않는다. 새로고침 후 개인정보를 브라우저 저장소에 보관하지 않는다. 이메일·오시는 길은 팝업과 기존 푸터에서 접근한다. 문의 전송은 기존 브라우저 기본 POST 동작이다.

## 검수
확정 9개 명칭·류진 제외·관계 구분, JS off 정적 명단과 문의 fallback, 320/390/1440px 넘침, 열기/닫기/재오픈·입력 보존·Esc·키보드 초점·배경 클릭·깊은 링크, 필수 입력 유효성 및 합성 POST payload(실제 접수 금지), 공개 회귀·Netlify 빌드를 확인한다. 사용자 승인 전 main/Production/운영 DB 변경 없음.

## 사용자 디자인 피드백 반영 (2026-11-10)
기존 왼쪽 CONTACT 제목·설명·이메일·오시는 길 두 카드 전체를 그대로 복원하고, 오른쪽은 문의하기 버튼만 두어 기존 팝업을 연다. 모바일은 원래 안내와 카드 다음에 버튼을 배치한다. 파트너 소개의 큰 흰색 카드 시안은 정리해 흰 바탕·기업명·작은 관계 표기·가느다란 구분선 중심으로 검토한다. 명단과 팝업 기능은 유지한다. 사용자가 즉시 홈페이지 게시를 원하지 않았으므로 이번 PR은 계속 디자인 검토용 Draft로 유지하며 main 병합·운영 배포를 보류한다.

## 하단 섹션 색상 재조정 (2026-11-10)
사용자가 콜라보레이션과 파트너 영역이 같은 흰색으로 이어지는 점을 지적해 색상 조정을 요청했다. 활동 기록 베이지 → 콜라보레이션 연녹색 → 파트너 흰색 → 문의 베이지 흐름으로 구분한다. 콜라보레이션의 제목·항목은 짙은 초록, 본문은 어두운 회녹색, 구분선은 옅은 초록으로 조정한다. 기존 문의 안내·우측 팝업 버튼·파트너 명단과 배치는 유지하며 프리뷰 검토만 진행한다. 이전 흰색 콜라보레이션 결정은 이 요청으로 대체한다. main 병합·운영 게시 보류는 유지한다.

## 문의 영역 2열 배치 확정 (2026-11-10)
사용자가 간단한 배치 시안을 확인했다. 이메일·오시는 길 카드는 왼쪽에 위아래로, 문의 버튼은 오른쪽에 배치한다. 버튼 아래 설명 문장은 넣지 않는다. 태블릿에서도 2열을 유지하도록 메인 문의 영역에만 기존 980px 전환 규칙을 덮어쓴다. 760px 이하 휴대폰은 카드 가독성을 위해 세로 배치를 유지한다. 786px 브라우저 검사로 태블릿의 좌우 배치를 확인한다. 프리뷰만 갱신하며 main·운영 게시 보류는 유지한다.

## 문의 섹션 시안 승인 (2026-11-10)
제목과 설명을 섹션 전체 위에 두고, 그 아래 왼쪽에는 기존 이메일·오시는 길 카드 두 개, 오른쪽에는 설명 없는 문의 버튼을 두어 카드 두 개의 중앙에 맞춘다. 세로 구분선은 제거하고 버튼을 넉넉하게 조정한다. 좁은 휴대폰에서는 세로로 배치한다. 문의 팝업·전송 경로와 콘텐츠 관리 선택자는 유지한다. 일러스트는 기존 자산을 조사해 활용 방안을 제안하며 사용자 시각 확인 전 추가하지 않는다.

## 협력 분야 기존 일러스트 활용 (2026-11-10)
사용자가 기존 4개 일러스트의 재사용을 요청해 메인 협력 분야 네 항목에 각각 기존 협력·포장검수·ESG·문화 그림을 배치한다. 장식용 일러스트로 사용하며 실제 현장 사진이나 성과의 증거로 표현하지 않는다. 좁은 화면은 2열이다. 신규 문의 일러스트는 별도 시안만 검토한다. 운영 게시 전 프리뷰에서 확인한다.

## 문의·태장 소개 일러스트 시안 (2026-11-10)
기존 4개 그림의 색감·그림체를 참고해 문의 영역의 봉투·식물 장식과 태장 소개의 함께 일하는 모습을 그린 일러스트를 제작해 Draft 프리뷰에 배치한다. 문의는 버튼의 독립성과 가독성을 유지하고, 소개의 연혁은 그대로 표시한다. 그림은 실제 직원이나 장소의 사진이 아닌 설명용이며, 운영 게시 전 사용자가 화면과 그림을 확인한다. 기존 콘텐츠·문의 기능은 유지한다.

## 문의 일러스트 위치 조정 (2026-11-10)
사용자의 프리뷰 피드백에 따라 문의 버튼 뒤에 겹쳐 가려지던 일러스트를 버튼 아래로 이동하고 전체 그림이 보이도록 원래 밝기로 표시한다. 버튼은 오른쪽 구역에 유지하고 작은 화면에서도 일러스트와 겹치지 않도록 한다.
