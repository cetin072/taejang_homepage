# Issue #149 — 근태 무결성 최종 운영 기준

## 근태 대상
- 대표이사(`ceo`)는 근태 기록 대상에서 제외한다.
- 운영총괄(`operations_manager`)은 근태 기록 대상에서 제외한다.
- 그 외 직원은 active/non-archived Employee이며 `attendance_required=true`일 때 근태 대상이다.
- 임원 제외는 Employee 직책 코드와 연결 계정의 활성 권한을 함께 확인해 데이터 불일치에도 안전하게 적용한다.
- 운영총괄은 본인 근태는 제외되지만 다른 직원의 출근부 관리·예외 검토·보정 권한은 유지한다.

## 일반 근태 기록
- GPS 60m geofence를 유지한다.
- 기록 시각은 서버 시각을 사용한다.
- 휴일/비근무일 guard를 유지한다.
- 위치 권한 거부는 관리자 예외 요청으로 우회하지 않는다.
- 위치 불확실 등 허용된 실패만 제한적으로 예외 요청할 수 있다.
- 본인의 예외 요청을 본인이 승인하거나 반려할 수 없다.

## 수동 보정 / 누락 추가
급여·정산에 영향을 줄 수 있으므로 운영총괄만 수행한다.

가능한 작업:
- 누락 출근시간 추가
- 누락 퇴근시간 추가
- 기존 유효시간 정정
- 잘못된 유효 기록 무효 처리

안전 원칙:
- 원본 `attendance_events`를 UPDATE/DELETE하지 않는다.
- `attendance_corrections` append-only 원장에 새 이력을 추가한다.
- 보정 사유 5자 이상 필수.
- 수정자와 수정시각을 저장한다.
- 이전 보정도 삭제하지 않고 `supersedes_correction_id`로 연속성을 남긴다.
- 출근/퇴근 순서가 뒤집히는 보정을 서버에서 차단한다.
- 대표이사·운영총괄·근태 비대상 직원에는 보정 기록을 만들 수 없다.

## 권한
- `promotion_lead`: 출근부 조회, 본인이 아닌 직원의 허용된 예외 승인/반려.
- `operations_manager`: 위 모든 권한 + 수동 보정/누락 추가/무효 처리.
- 일반 직원: 본인 근태 조회/기록/허용된 예외 요청만 가능.

## 감사와 테스트
- 자기승인 차단 시도를 audit에 남긴다.
- 수동 보정 생성도 audit에 남긴다.
- clean migration, db lint, pgTAP, 실제 Auth/Data API 통합 테스트를 required CI에서 수행한다.
- 기존 60m geofence와 server-time 계약은 회귀시키지 않는다.


## 결정 이력 — 2026-09-23 / Issue #362

상태: **확정**

### 직원앱 단일 출퇴근 버튼
- 직원이 이해해야 할 상태를 늘리지 않고 기존 단일 버튼 흐름을 유지한다.
- 출근 전: `출근했습니다`
- 출근 완료 후: `퇴근했습니다`
- 퇴근 완료 후: `오늘 근무 완료`
- 별도의 `근무 중입니다` 행동 버튼은 만들지 않는다.

### 출근 가능 시각
- 실제 직원 출근 기록은 서버 한국시간(`Asia/Seoul`) 기준 **오전 06:00부터** 허용한다.
- 00:00~05:59에는 앱에서 `출근 전입니다` / `오전 6시부터 출근할 수 있습니다`로 표시하고 행동을 비활성화한다.
- 앱 표시만으로 보호하지 않고 실제 기록 RPC와 허용된 출근 예외 요청도 서버에서 06:00 이전을 거절한다.
- 모바일은 휴대폰 로컬 시각으로 출근 가능 여부를 독립 판정하지 않고 서버가 내려준 상태를 표시한다.

### 퇴근
- 퇴근에는 최소 시각 제한을 두지 않는다. 출근 직후 조퇴하는 실제 운영도 기록할 수 있어야 한다.
- 퇴근은 유효한 출근이 먼저 있어야 한다는 기존 서버 규칙을 유지한다.
- `퇴근했습니다` 행동 시 기존 `정말 퇴근하시겠습니까?` 재확인을 유지한다.

### 휴일과 휴일근무
- 일반 휴일/비근무일에는 출근 행동을 노출하지 않고 `오늘은 출근일이 아닙니다` 상태로 비활성화한다.
- 기존 `attendance_holiday_work_assignments`에 사전 지정된 직원은 해당 휴일을 개인 유효 근무일로 취급하여 정상 출퇴근할 수 있다.
- 휴일근무 지정 직원에게는 `휴일근무일입니다` 안내를 표시한다.
- 휴일근무 지정 권한, 원장, 감사이력 구조는 변경하지 않는다.

### 유지할 안전 경계
- 하루 출근 1회 / 퇴근 1회의 기존 DB 유일성·idempotency를 유지한다.
- GPS 60m geofence, 서버 기록시각, 위치 예외 정책을 변경하지 않는다.
- 운영총괄의 무기록 attendance QA는 실제 직원 기록과 분리하여 06:00 제한 없이 유지한다.
