# 인증·지정 및 참여기업 소개 V1

2026-11-10 사용자 요청: 인증 회사 소식의 사진을 첨부한 인증서와 보정된 현판 3장으로 교체하고, 인증·동행일자리·참여기업을 소개하는 독립 페이지로 연결한다. 이번 범위는 구현과 검증이며 main 병합·즉시 운영 배포는 별도다.

- 인증서 원본 제2026-049호, 2026.07.09, 한국장애인고용공단. 인증서 이미지 원본 바이트를 보존한다.
- 현판 3장은 사용자가 제공·공개 요청한 AI 사진 보정본으로 WebP 최적화만 한다. 작은 문구·로고 재구성 가능성을 고려해 현판에 사진 보정본 표시, 공식 내용은 인증서 원본으로 확인하도록 한다.
- 경남형 장애인 동행일자리 제1호 사업장과 표준사업장 인증은 별도 절로 설명한다. 공동출자 현판을 별도 인증으로 설명하지 않는다.
- 회사 소개·협력 페이지의 기존 인증 소식 연결을 certifications.html로 바꾼다. 원래 소식 URL·발행일은 보존하고 새 페이지에서 소식으로 연결한다.
- 기존 공통 헤더·푸터·타입·색상 재사용, 추가 JS 없이 이미지 원본 링크와 섹션 앵커로 구성한다.
- 검수: 이미지 무잘림·모바일 넘침·JS off·키보드/앵커·링크·빌드 포함·sitemap·원본 보존·기존 공개 회귀.

## 표현 변경 및 main 병합 승인 (2026-11-10)
사용자가 공개 화면에서 ‘보정본’ 안내를 빼고 ‘현판 사진’으로만 표시하도록 요청했고 main 병합을 승인했다. 캡션·대체텍스트·기존 소식에서 보정 설명을 제거한다. 이미지 파일·배치·인증서 원본·기타 내용은 유지한다. 앞선 보정본 표시 결정은 이 공개 문구 결정으로 대체한다.
