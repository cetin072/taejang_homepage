## 승인된 범위와 이전 기준 변경

사용자가 승인한 6단계 개편을 실행한다. 가치·정체성·실제 사진 → 출자/거래/운영 관계 → 확인된 참여기업 → 실제 활동 증거 → 기업 검토 정보·FAQ → 기존 문의창.
기존 ‘함께하는 방법’ 4개 일러스트 카드와 ESG 중복 설명은 이 구조로 통합한다. 기존 자산 파일은 삭제하지 않는다. 아래 보존한 2026-08-27 기록 및 #66의 카드 유지 기준 중 이번 요청과 충돌하는 화면 구성만 대체한다. 새 시스템·랜딩페이지·가격 계산기·다운로드 자료를 만들지 않는다.

두 CTA는 기존 유형 `모회사·고용 연계` / `기업 업무·건별 프로젝트`를 선택한다. 농장 전용 유형을 새로 만들지 않고 사업 협력의 세부 내용으로 받는다. 기존 옵션 전체, form-name, 필드, POST, 완료 주소, 동의·honeypot·알림 계약은 유지한다. 새 제출 핸들러가 없으며 입력값 초기화도 하지 않는다. JS off에서 기본 폼과 FAQ 본문을 읽을 수 있다.

## 2026-10-28 사용자 화면 피드백 반영

- 같은 공개 기록으로 이동하던 기업별 링크 4개를 섹션 공통 링크 1개로 통합한다.
- 기업별로 반복되던 관계 라벨·동일 설명은 상단 공통 설명으로 모은다. 기업명은 모바일에서도 2열의 짧은 목록으로 표시한다.
- 작업 지시문처럼 읽히던 제목 `기업 담당자가 검토할 정보`는 공개 화면에서 `참여 안내`로 바꾼다. 절차와 FAQ 내용·문의 계약은 그대로 유지한다.
- 동일 링크 반복·제목 회귀를 기존 정적 검사와 브라우저 검사에 추가한다. 이번 로컬 검수는 변경된 목록·공통 링크·제목과 레이아웃만 확인하며 문의 제출 검사를 반복하지 않는다.

## 2026-10-28 Hosted 검수 오류와 예방 수정

- 초기 검수 코드는 `/thanks.html`만 가로챘지만 Netlify가 실제 HTML의 action을 `/thanks`로 정규화했다. 이로 인해 `개발 검수용` 이름, `합성 QA 기관`, `qa@example.invalid` 이메일과 합성 본문으로 구성된 요청 **1건**이 외부로 나갔다. 실제 고객정보는 사용하지 않았다.
- Netlify 읽기 전용 요청 기록에서 2026-10-27 23:49:26 UTC (2026-10-28 08:49:26 KST) Preview `/thanks`의 POST 1건·HTTP 200을 확인했다. Forms 최신 접수 시각도 일치한다. 개별 접수 원문과 담당자 알림 도착은 확인하지 못했다. 기록을 삭제하지 않았다.
- 예방: 브라우저 context 생성 직후 모든 비조회 메서드를 기본 차단한다. 폼의 실제 action이 같은 origin의 `/thanks` 또는 `/thanks.html`인지 먼저 검사하고, 그 요청에만 합성 실패 응답을 반환한다. 다른 모든 쓰기는 abort한다. 차단 성공을 확인하기 전 제출 완료로 판단하지 않는다.
- 원래 action과 Netlify의 clean action을 각각 로컬에서 재현해 요청 구성·입력 보존을 검사한다. Hosted 검사도 같은 차단 경계로 수행한다. 기존 홈페이지 폼 원문은 변경하지 않는다.

# 공개 홈페이지 협력 콘텐츠·FAQ v1

> 상태: **확정**
> 적용 Issue: [#54](https://github.com/cetin072/taejang_homepage/issues/54)

## 1. 페이지 목적과 흐름

`partnership.html`은 방문자가 태장과 함께할 수 있는 일을 이해하고 궁금증을 해소한 뒤 문의를 남기도록 다음 흐름을 유지합니다.

`히어로 → 참여기업 → 함께하는 방법 → ESG 상세 → FAQ → 문의`

## 2. 확정 구현 기준

- `함께하는 방법`의 기존 4개 일러스트와 디자인 톤은 유지합니다.
- 4개 카드는 상세 절차가 아닌 협력 분야의 입구로 사용하며, 문구는 짧고 협력 중심으로 작성합니다.
- ESG 카드는 `환경정비 등 지역사회 활동을 기업·기관과 함께 검토합니다.` 수준으로 축약하고 `#environment-service` 상세 섹션으로 연결합니다.
- ESG 상세에는 현재 활동(지역 환경정비), 협력 가능한 방향, 사전 협의, 현장 준비, 수행·기록을 한 곳에서 설명합니다.
- FAQ는 ESG 상세와 문의 영역 사이에 6개를 배치합니다. 처음에는 답변을 접고, 질문 버튼을 누르면 하나씩 펼칩니다.
- FAQ는 기존 `assets/js/site.js`의 `[data-faq-button]` 동작을 재사용하며, 질문은 native `button`으로 만들어 키보드 사용과 `aria-expanded`를 보장합니다.
- 표준사업장 제도·고용부담금·지원제도 설명은 FAQ에 추가하지 않습니다.

## 3. FAQ 확정 문구

1. 어떤 업무를 태장과 협의할 수 있나요? — 포장·검수 등 반복 업무, 민화·문화 굿즈, 지역사회공헌 활동 등 현재 태장이 운영하거나 검토할 수 있는 범위에서 협의합니다.
2. 작은 규모의 업무도 문의할 수 있나요? — 네. 업무의 수량이나 규모만으로 먼저 판단하지 않고 작업 내용, 일정, 방식 등을 함께 확인합니다.
3. 처음부터 구체적인 제안서를 준비해야 하나요? — 아닙니다. 필요한 업무와 희망 일정 정도만 알려주셔도 검토를 시작할 수 있습니다.
4. 환경정비나 ESG 활동은 어떻게 진행되나요? — 장소와 규모를 확인한 뒤 필요한 경우 현장 확인, 범위 조정, 준비와 안전 안내를 거쳐 진행합니다.
5. 민화·문화제품 제작도 문의할 수 있나요? — 가능합니다. 제작 목적, 수량, 일정 등을 알려주시면 현재 가능한 범위를 확인합니다.
6. 채용이나 근무 관련 문의도 여기서 할 수 있나요? — 가능합니다. 문의 유형에서 `채용·근무 문의`를 선택해 내용을 남겨주세요.

- 별도 FAQ 페이지나 새 라이브러리는 만들지 않습니다.
