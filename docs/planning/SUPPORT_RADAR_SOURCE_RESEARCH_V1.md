Status: **검토 중**  
Parent: #161  
조사일: 2026-09-09  
목적: 구현 전 공식 Source별 접근방식을 확인하고 `공식 API → 공개데이터 → 공개검색/HTML → 수동등록` 우선순위를 정한다.

## 1. 1차 결론

초기 Source는 한꺼번에 모두 자동화하지 않는다.

### Phase 2 자동연결 최우선

1. **기업마당 지원사업정보 API**
2. **국고보조금/e나라도움 공개 Open API**

둘 다 공식 구조화 데이터 경로가 확인되므로 크롤링보다 먼저 사용한다.

### Phase 1~2 공식 웹/수동 우선

3. 한국장애인고용공단
4. 경남기업119
5. 창원산업진흥원
6. 창원특례시 고시공고/기업지원
7. 농림축산식품부
8. 한국농수산식품유통공사(aT)
9. 한국문화예술위원회
10. 중소벤처기업부 사업공고

위 Source들은 태장 적합성이 높지만 이번 조사에서 `지원사업 전체를 안정적으로 가져오는 공식 전용 API`까지 확인되지 않은 경우가 있어 Phase 1에서는 Source Registry + 수동/공개 URL 등록을 우선한다.

## 3. 기업마당

공식 `정책정보 개방` 페이지에서 다음이 확인된다.

- 중앙부처·지자체·유관기관 최신 지원사업 공고 제공
- `지원사업정보 API`
- REST
- JSON/XML
- 기관별·분야별 지원사업 정보
- API 사용신청 구조

### 판단

**태장 레이더의 전국 기업지원 기본 Feed 1순위.**

Phase 2에서 가장 먼저 실제 API 연결을 검토한다.

### 구현 전 추가확인

- 이용신청/인증키 발급 절차
- 호출한도
- 응답 필드
- pagination
- 공고 ID의 안정성
- 수정공고 처리방법
- 첨부파일 URL 제공 여부
- 지역/분야 필터 값

## 4. e나라도움 / 국고보조금 Open Data

공공데이터포털에서 국고보조금 정보의 Open API 및 파일데이터 제공이 확인된다.

특히 `국고보조금 공모사업 상세` 데이터는 공모 관련 정보, 사업 목적·규모·지원내용·신청방법·선정기준·재원구성 등을 제공하는 구조로 안내된다.

### 판단

기업마당과 성격이 다르며, 기업지원 이외의 국고보조 공모를 잡기 위해 **S급 Source**로 둔다.

태장이 직접 신청할 수 없는 비영리/수행기관형 공모도 공동·협력 후보로 분석하는 데 중요하다.

### 구현 전 추가확인

- 실제 Open API 상세 endpoint
- 서비스키 발급조건
- 조회기간 조건
- 공모 상태값
- 신청대상/수행기관 정보의 구조화 수준
- 첨부/원문 URL
- 업데이트 시간

## 5. 한국장애인고용공단(KEAD)

태장에게는 일반 기업보다 우선도가 매우 높은 특화 Source다.

공식 페이지에서 장애인표준사업장 지원의 예로 다음 지원영역이 확인된다.

- 작업시설·부대시설·편의시설 설치·구입·수리·개선
- 장애인 출퇴근 편의를 위한 승합자동차
- 장애인 고용관리 전문가 임금 일부
- 표준사업장 생산품 판로확대를 위한 인증·컨설팅

지원사업 신청시기는 공단 홈페이지 공지사항에 별도 공고하는 구조다.

자료실과 공지사항도 별도로 운영된다.

### 판단

**태장 특화 S급 Source.**

구조화 API가 확인되지 않아도 중요도가 높으므로 Phase 1에서 공식 URL 수동등록과 사람 검토를 바로 지원해야 한다.

### 구현 전 추가확인

- 공단 공지사항/사업주지원 게시판의 공고 분류
- 표준사업장/고용장려/보조공학/시설·환경개선 등 하위 Source 분리 필요 여부
- RSS/API 존재 여부
- 자동접근 이용조건

## 6. 경남기업119

경상남도 공식 기업지원 포털에서 다음과 같은 분야별 지원사업 구분이 확인된다.

- 기술
- 금융
- 수출
- 인력
- 창업
- 경영
- 내수
- 기타

현재 지원사업 공고가 지속적으로 게시되는 구조다.

### 판단

태장의 경상남도 소재 조건 때문에 **A급 지역 Source**.

기업마당에 재게시되는 공고가 있을 수 있으므로 `support_notice_occurrences` 중복구조가 필요하다.

---

## 7. 창원산업진흥원

공식 `지원사업 신청` 화면에서 다수 사업을 검색할 수 있으며 사업공고명, 지원팀, 담당자, 신청기간, 접수상태가 표시된다.

지원영역에는 현재 다음과 같은 항목이 확인된다.

- 수출/마케팅
- 전시회
- 인력양성/창업
- ESG
- 기술/기업지원 등

### 판단

**창원 지역 기업지원의 매우 중요한 Source.**

태장 지역조건과 AI·ESG·제조·판로 분야 때문에 초기 우선순위를 S/A로 둔다.

---

## 8. 창원특례시

창원시 공식 고시공고에는 기업지원뿐 아니라 농업, 지역일자리, 각종 모집공고가 함께 게시된다.

별도 기업지원 안내에는 중소기업육성자금 등 기업 대상 지원공고가 존재하며, 농업기술센터 공고에도 농업 관련 지원·수요조사·모집이 확인된다.

### 판단

태장의 의창구 사업장과 진전면 농장 때문에 반드시 포함해야 하지만 게시범위가 매우 넓다.

따라서 단순 전체 크롤링보다 다음 필터를 우선한다.

- 지원
- 모집
- 기업
- 농업
- 농촌
- 장애인
- 일자리
- 시설
- 장비
- ESG
- 문화
- AI

그리고 농업기술센터/기업지원/일자리 등 하위 Source를 논리적으로 분리하는 방안을 검토한다.

---

## 9. 농림축산식품부 / aT

농림축산식품부 공식 공지·공고에는 농업·농촌형 예비사회적기업 등 공모가 게시된다.

aT는 2026년 정책자금 종합안내와 식품·외식기업 지원사업 정보를 제공하고 있으며 농식품 제조·가공업체, 수출업체 등 기업 대상 지원이 존재한다.

### 판단

태장의 농업회사법인·제조업·농식품 확장 가능성 때문에 **A급 Source**.

기업마당과 중복되더라도 원기관 공고를 근거 Source로 보존할 가치가 있다.

---

## 10. 한국문화예술위원회

공식 공모 안내에서 연도별 문예진흥기금 사업과 신청기간을 제공한다.

태장의 민화·문화예술 직무는 직접 기업 신청이 불가능한 공모도 있을 수 있으므로 A/B/C 판정이 특히 중요하다.

### 판단

**문화 분야 A급 Source.**

직접신청 불가 공고라도 협력기관/예술단체와 공동 수행 가능성을 검토하기 위해 단순 제외하지 않는다.

---

## 11. 중소벤처기업부

공식 사업공고 게시판에는 스마트서비스, 스마트공장 등 AI·디지털·제조 관련 지원사업이 지속적으로 게시된다.

기업마당이 중앙·지자체·유관기관 사업을 폭넓게 제공하므로 상당 부분 중복될 가능성이 있다.

### 판단

기업마당 API의 coverage를 검증하는 **원기관 Source**로 유용하다.

Phase 1 Golden Set에서 동일 공고의 기업마당 occurrence와 중기부 occurrence를 연결해 중복구조를 검증하는 사례로 쓰기 좋다.

## 13. Phase 1 Source 작업 완료기준

Phase 1에서는 다음까지만 완료하면 된다.

- 위 Source를 Registry에 등록할 수 있다.
- 사람이 Source URL에서 발견한 공고를 수동등록할 수 있다.
- 하나의 공고에 여러 Source occurrence를 붙일 수 있다.
- 원기관 Source와 집계 Source를 모두 보존할 수 있다.
- 자동수집 전 이용조건 검토상태를 기록할 수 있다.
- 기업마당/e나라도움 API 연결을 위한 필드 mapping 설계가 가능하다.

대규모 자동수집 자체는 Phase 1 완료조건이 아니다.

## 14. 후속 기술조사 순서

1. 기업마당 API 신청·샘플응답·rate limit·필드 mapping 확인
2. 국고보조금 공모 Open API endpoint·서비스키·필드 mapping 확인
3. KEAD 공식 게시판 RSS/API/접근정책 확인
4. 창원산업진흥원/경남기업119 공식 데이터 제공수단 확인
5. 창원시 고시공고 하위분류와 검색조건 정리
6. 농업·문화 특화 Source 보강

위 순서로 조사한 뒤에만 실제 자동수집 구현 Issue를 연다.
