# 소식·기록: 기획기사 우선 노출과 기록 탐색

2026-11-14 사용자 확정: 기획기사는 운영총괄이 우선 읽히고 싶은 글을 선정해 고정하는 영역이다. 최신순 일반 소식과 역할이 다르며 상단 고정, 최대 4개, 일반 카드보다 특별한 디자인을 유지한다. 구현 승인 범위이며 main 병합·운영 배포는 별도다.

## 디자인 방향
- 목적: 선정한 기획기사를 먼저 읽고, 직원 일상과 활동 기록을 검색한다.
- 성격: 차분함, 정성, 편집의 무게.
- 소재: 태장의 실제 작업 사진과 기록, 기존 녹색·명조/고딕.
- 강조: 상단 기획기사의 녹색 프레임·금색 선·전용 표식, 실제 사진.
- 일관된 특징: '기획기사' 표식. 자동 회전·등급 문자·발광 효과는 추가하지 않는다.

## 구현
기존 고정 ID·순서·공개 승인 검증을 재사용하고 최대 4개까지 지원한다. 현재 선정된 실제 글은 1개다. 1개는 PC 사진/설명 가로 배치, 2~4개는 개수별 그리드, 모바일 다중 카드는 다음 카드가 일부 보이는 수동 가로 스크롤이다. 홈페이지의 기존 별도 카드 디자인은 유지한다.

빌드 때 이미 공개 승인된 고정 글의 수만 이용해 로딩 공간을 확보한다. 실제 기획기사 내용은 기존 실시간 공개 피드 검증 후 표시한다. 실패·비공개 글은 표시하지 않으며, 늦은 응답으로 영역 높이가 달라져도 검색 중인 위치를 보존한다. 새 API·DB·권한·관리 기능은 없다.

전체 소식은 검색→접이식 출처/주제/기간→선택 조건/초기화→날짜순 기록이다. 일반 목록의 동일 기획기사와 블로그 원문은 삭제하지 않는다. 제목의 HTML 문자, 반복 회사명 접미사, 반복 인사말·무의미한 기본 요약은 표시에서만 정리하며 원본/검색 데이터는 유지한다. 기획기사 소개문은 확인된 본문에 맞춰 기존 설정에 기록한다. HTML 문자열을 DOM으로 실행하지 않는다.

## 아홉 항목 점검
간격(4px 간격 체계), 색(기존 녹색과 기획기사 금색), 아이콘(SVG 돋보기·삭제 하나), 문구(핵심 소개/원본 보존), 글자(한글 출처·날짜 정렬·제목 가독성), 배치(1~4개/모바일), 세부(48px 필터·44px 삭제·초점·8px 컨트롤), 사진(기존 공개 사진·대체 설명), 움직임(수동 스크롤·색상 변화·감소 설정)을 확인한다. 한글 서체는 기존 브랜드 조합을 유지한다.

## 검증
193개 기존 공개 테스트 및 관련 회귀, 생성 HTML/JS 동일 표시, 320/390/786/1440px 기획기사 1~4개 fixture, 지연/실패 피드, 검색/필터/초기화/더보기/키보드/가로 넘침과 버튼이 카드 안에 표시되는지 검사한다. fixture는 브라우저 네트워크에만 주입하며 공개 데이터에는 등록하지 않는다. 실제 결과는 PR/CI에 기록한다.
