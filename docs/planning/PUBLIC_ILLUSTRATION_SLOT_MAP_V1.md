# 공개 홈페이지 일러스트 슬롯 맵 v1

> 상태: **기획 확정 / 실제 일러스트 제작은 개별 승인 후**  
> 기준: Issue #56, `PUBLIC_ILLUSTRATION_STYLE_GUIDE_V1.md`  
> 목적: 시간이 지난 뒤에도 어떤 위치가 설명용 일러스트 후보인지 직관적으로 확인하고, 실제 그림 제작 전에 위치와 주제를 먼저 판단할 수 있도록 슬롯을 고정한다.

## 운영 원칙

- 실제 사람·제품·사업장·성과를 증명하는 곳은 실사 사진을 우선한다.
- 관계·구조·방향·확장을 설명하는 곳은 수채화 설명 일러스트를 검토한다.
- 숫자·단계·공정·비교가 핵심이면 CSS/간결한 인포그래픽을 우선한다.
- 단순히 화면이 비어 보인다는 이유로 일러스트를 추가하지 않는다.
- 미제작 슬롯은 Draft/Preview에서 짧은 박스로 표시할 수 있다.
- placeholder는 실제 그림으로 오해되지 않도록 `ILLUSTRATION SLOT` 및 슬롯 문자(A, B, C...)를 표시한다.
- placeholder는 Production에 장기 노출하는 최종 콘텐츠가 아니다. 실제 일러스트 제작 또는 슬롯 철회 후 제거한다.

- 메인 페이지를 과밀하게 만들 경우 실제 제작을 취소할 수 있다.

- 현재 운영 사례 자체는 계속 실제 사진을 사용한다.

상태:
- 위치 후보 확정

## 의도적으로 새 일러스트 슬롯을 두지 않는 영역

### `workplace.html`
실제 근로자, 작업 방식, 작업 공간을 보여주는 페이지이므로 **실사 우선**. 현재 실제 민화·포장·작업공간 사진을 유지한다.

### `greeting.html`
대표 인사말은 대표이사 실사 사진과 문장이 핵심. 별도 수채화 일러스트를 추가하지 않는다.

### `archive.html`
실제 소식과 기록이 핵심. 게시물·활동의 실제 썸네일/사진을 사용한다.

### `location.html`
실제 방문정보가 핵심. 필요 시 지도 또는 실제 건물/입구 사진을 사용하며 설명용 수채화 일러스트는 추가하지 않는다.

### `business.html` 테라리움
실제 샘플이 있으므로 실사 유지.

### `partnership.html` 상단 4개 협력 카드
이미 승인된 공식 설명 일러스트가 존재하므로 교체 또는 추가 슬롯을 만들지 않는다.

### FAQ
정보 탐색성이 우선이므로 별도 일러스트를 넣지 않는다.

## placeholder 표시 규칙

실제 그림이 없는 C/D/E/F는 Draft/Deploy Preview에서 다음처럼 짧게 표시할 수 있다.

예:

`C · ILLUSTRATION SLOT`

`참여기업 4개사 → 태장 → 맞춤 직무 → 실제 사업과 일자리`

`후속 일러스트 예정`

규칙:
- 2~3줄 이내
- 연한 아이보리/크림 배경
- 옅은 세이지/올리브 테두리
- 둥근 모서리
- 작은 슬롯 배지(A/B/C...)
- 긴 문서형 설명, GitHub UI, 체크리스트 형태 금지
- 모바일 가로 스크롤 금지
- 실제 페이지 분위기를 해치지 않는 최소 높이

## 구현 순서

1. PR #59(A/B 적용 및 최적화)를 먼저 독립적으로 마무리한다.
2. PR #59에 C/D/E/F placeholder 작업을 섞지 않는다.
