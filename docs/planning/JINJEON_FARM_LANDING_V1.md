# 진전면 농장 소개 V1

상태: 확정. 2026-11-10 사용자가 작성 초안을 승인하고 구현 진행을 요청했다.

## 목적과 승인 내용
팔용동 본점과 진전면 농장이라는 두 거점을 구분해 소개한다. 기존 공개 홈페이지의 정적 HTML·브랜드·메뉴·문의 기능을 재사용한다.

- farm.html: 첫 소개, 이전 본점 이야기, 위치/규모/시설, 야생다래 덕장과 2년 연속 호박 재배 완료, 단계적 개발, 두 거점, 문의.
- about.html은 기존 4칸 중 소재지 카드만 '태장의 두 거점'으로 변경한다.
- business.html에 농업 기반 소개, location.html에 두 거점 구분, history.html에 현재 농장 소개 링크를 추가한다.
- 공식 검색 제목/설명·canonical·OG/Twitter·WebPage/Place·BreadcrumbList를 제공하고 정적 sitemap/build allowlist에 포함한다.
- 농장 문의는 기존 partnership.html#contact로 이동한다. 새 입력/예약/자동 발송/관리자 기능을 만들지 않는다.

## 제외와 후속
농장사진은 추후 전달. 현재는 텍스트와 기본 정보로 완결된 레이아웃을 제공하며, 깨진 이미지/빈 슬롯/가상 농장 이미지를 넣지 않는다. 이후 승인된 전경은 hero, 덕장과 호박 재배 사진은 각 시설/재배 카드에 적용한다.
상세주소/지번/좌표/지도/방문예약·체험/판매/작물 수량/근로자 배치/수확연도/소유·임대 조건은 임의 확정하지 않는다. 미담농원 자료와 혼합하지 않는다.
main 병합·운영 배포·고정 QA 교체는 이번 구현 승인과 별개다.

## 검증 및 완료 대조
정적 본문·문의·내부 이동은 JS 실패에도 남는다. 기존 public regression과 build를 실행한다. 기존 SEO browser 검사에 농장 entrypoint와 320/390/1440px, JS on/off, 실제 앵커 이동·문의 페이지 도착, 가로 넘침·안정성·스크린샷을 추가한다. 실제 문의 제출과 DB 쓰기는 하지 않는다.
본문/정적 연결/검색 데이터: 구현. 사진과 상세 위치: 의도적으로 후속. 실행 결과와 최신 HEAD/CI/Preview는 Draft PR에 기록한다.

## 최종 문구 정리 및 병합 승인 (2026-11-10)
사용자가 최종 문구 수정안 적용과 main 반영을 승인했다. 첫 제목은 '태장 진전면 농장'으로 명확히 하고, 이전 본점 설명은 농장 이야기에서 다룬다. 시설 설명의 추상적인 뒷문장과 단계적 개발 설명의 반복을 제거한다. 호박 설명은 '두 해 연속 호박 재배를 마쳤습니다'로 정리한다. 하단 거점 비교에서는 역할만 요약하고, 문의 제목은 '농장 문의·협력 제안'으로 변경한다. 시설·재배 완료·개발 중 상태와 사진 후속 원칙은 유지한다. 기존 4개 진입 링크를 보존한다. 최신 검사 통과 후 같은 PR #632를 병합하며 즉시 운영 배포는 이번 승인 범위에 포함하지 않는다.

## 2026-11-14 농장 소개 개선 재개 승인

사용자는 검수 제안 후 중단했던 작업의 재개를 요청했다. 오시는 길에서는 만 평 컨셉 이미지를 제외하고, 농장 상세 페이지는 제안한 구성으로 개발한다.

- 첫 화면: 기존 제목·위치와 약 1만 평 강조를 유지하고 승인된 수채화를 재사용한다. ‘농업 공간을 표현한 컨셉 이미지’ 캡션을 붙인다. 이는 기존 가상 실경 제외 원칙을 유지하면서 장식용 컨셉 이미지 사용을 허용하는 변경이다. 실제 시설·경계의 증거로 쓰지 않는다.
- 본문: 농장의 시작 → 시설·재배 경험과 현재 개발 → 문의 순서. 중복 위치/규모 표와 두 거점 카드, 반복 영문 라벨을 제거한다. 팔용동 안내는 하단 짧은 안내와 링크로 유지한다.
- 시설·재배 완료·개발 중 상태를 구분하고 신규 시설/예약/수확 실적은 주장하지 않는다.
- 버튼: 이동은 기존 테두리 버튼을 재사용하며 화살표·모서리·터치 높이를 맞춘다. 문의는 상단·하단, 본점 안내는 하단에 둔다.
- 검수: 기존 public SEO browser 검사에서 컨셉 이미지 출처·캡션·비율, JS on/off, 좁은 화면, 앵커·문의 이동을 확인한다. 별도 JS·새 외부 의존성 없음.
- 승인 범위: 농장 상세는 개발·검수. 오시는 길 이미지 제외 건만 main 병합 승인. 운영 배포 제외.

위 항목 구현 완료. 실제 농장 사진·상세주소·예약 기능은 후속 또는 제외 상태를 유지한다.
