# 우리의 일터와 포장·검수 상세의 역할

## 확정 결정 — 2026-11-14

사용자 승인: ‘우리의 일터’는 민화, 테라리움, 지역 환경정비, 포장·검수와 수작업을 함께 소개한다. PR #672의 포장 중심 첫 화면과 네 단계 작업 설명은 기존 `/workplace/packing-care.html` 상세로 옮긴다. 상위 페이지가 포장 하나의 상세처럼 보인다는 사용자 검수에 따른 변경이다.

- 하는 일: 고객이 의뢰하거나 구매할 수 있는 사업·서비스.
- 우리의 일터: 근로자가 참여하는 여러 작업과 사람에 맞추는 작업 방식.
- 포장·검수 상세: 실제 포장 사진, 준비·안내·포장·확인의 네 단계, 보조 일러스트. 기존 상세 URL과 옛 `?id=packing-care` 연결을 유지한다.
- 개요의 네 작업은 동등한 비중으로 소개한다. 별도 기록 목록의 중복은 없애고, 기존 작업환경 글은 공통 지원 설명에서 연결한다.
- 공개된 기존 사진과 기록을 재사용한다. 테라리움 샘플은 샘플로 표시하고 작업 중인 현장으로 설명하지 않는다. 미확인 작업 범위·수주 실적·생산량은 추가하지 않는다.
- 새 CMS·데이터 저장·권한 변경은 없다. 기존 정적 상세 생성과 JS 없는 기본 정보를 유지한다.
- 구현 승인 범위이며 main 병합과 운영 배포는 별도 승인 이후 진행한다.

## 디자인 검토

차분한 태장 녹색과 기존 명조·고딕 조합을 유지한다. 사진은 작업과 재료의 실제 모습을 보여주고, 설명은 사진 밖에 둔다. 개요에는 한 작업을 대표로 크게 강조하지 않는다.

| 점검 | 적용 |
| --- | --- |
| 간격 | 동일 작업의 사진·설명·링크 간격 통일, 작업 사이 48~64px |
| 색상 | 기존 녹색·중성 배경 유지, 장식 색상 추가 없음 |
| 아이콘 | 제목 장식 없음, 링크 방향 화살표만 같은 간격으로 사용 |
| 문구 | 사업 홍보와 작업 소개 분리, 링크 목적 명시 |
| 글자 | 기존 한글 서체 유지, 본문 17px·캡션 14px |
| 배치 | 네 작업 2열, 모바일 1열, 포장 공정은 상세로 이동 |
| 세부 | 버튼 높이 48px·모서리 8px, 사진 모서리 12px, 키보드 초점 |
| 이미지 | 승인된 기존 사진 자연 비율 유지, 수채화는 상세에서 일러스트로 표시 |
| 움직임 | 새 자동 애니메이션 없음, 버튼 호버는 색상 변화 |

디자인 점검 참고: [Unslop](https://github.com/heydamir/unslop), Damir Sokolovsky, CC BY 4.0. 사용자 승인에 따라 페이지 구성과 순서를 변경했다.

## 수용 기준

네 작업의 균형, 상세 진입·복귀, 기존 상세 주소·검색 메타데이터 유지, JS 활성/비활성, 320·390·786·1440px에서 이미지 비율·가로 넘침·버튼 크기·초점 확인. 구현 및 검사 상태는 PR #672의 현재 HEAD와 CI에 기록한다.

## 링크와 농장 안내 보완 — 2026-11-14

사용자 피드백에 따라 민화·테라리움은 각각 `why-minhwa.html`, `terrarium.html` 랜딩페이지로 연결한다. 기존 작업 기록은 삭제하지 않는다. ‘하는 일’에 있던 진전면 농장 소개를 ‘우리의 일터’ 하단에서도 짧게 안내하고 `farm.html`로 연결한다. 네 작업과 공통 작업환경 소개 다음에 농장을 배치하며, 확인된 약 1만 평·이전 본점·단계적 개발 설명을 재사용한다. 농장을 상시 체험장이나 현재 생산 중인 직무로 표현하지 않는다.
