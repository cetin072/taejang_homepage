# 공개 홈페이지 사업·일터 페이지 역할 분리 v1

> 상태: **확정**  
> 적용 Issue: [#52](https://github.com/cetin072/taejang_homepage/issues/52)  
> 적용 범위: `business.html`, `workplace.html` 및 해당 회귀 검사

## 1. 목적과 사용자

처음 방문한 기업·기관 담당자는 태장이 맡을 수 있는 사업과 협력 가능 업무를 빠르게 이해해야 합니다. 근로자·가족·기관 방문자는 일터의 직무와 실제 작업 방식, 작업환경을 이해해야 합니다. 두 목적이 섞여 같은 사업 설명·단계·사진을 반복하지 않도록 페이지 역할을 분리합니다.

## 2. 확정 화면 역할

| 페이지 | 핵심 질문 | 주요 관점 | 반드시 유지할 요소 |
| --- | --- | --- | --- |
| `business.html` | 무엇을 하는가 / 무엇을 맡길 수 있는가 | 사업·서비스·제품·기업 협력 | 현재 운영 사업 카드, 개발 중 사업, 협력·문의 연결 |
| `workplace.html` | 어떻게 일하는가 / 어떤 직무와 작업환경인가 | 사람·직무·작업 순서·일터 | 직무 이해에 필요한 최소 사진·직무명, `일터 이야기` 목록 및 상세 기능 |

## 3. 확정 구현 기준

- `business.html`은 기업·기관 담당자가 현재 운영 사업, 협력 가능 업무, 준비 중 사업을 구분해 이해하도록 문구와 협력 흐름을 구성합니다.
- `workplace.html`은 사업 소개를 반복하지 않고, 직무명·작업 단계·안내와 확인 방식·작업 공간을 중심으로 설명합니다.
- 두 페이지에서 같은 사진을 반복하지 않습니다. 단, 직무 맥락상 필요한 최소 사진·직무명은 `workplace.html`에 유지할 수 있습니다.
- `business.html`의 `지역사회공헌·ESG 협력` 카드에는 기존 공개 자산 `assets/images/archive/environment-cleanup-first.webp`를 사용합니다. 해당 자산은 첫 환경정비 활동의 공개 기록에 이미 사용 중인 실제 사진입니다.
- 사업 상태는 공개 기준에 따라 현재 운영·현재 활동·협력 방향·준비 중을 구분하며, 미확정 사업이나 법적·재무상 효과를 확대해 표현하지 않습니다.

## 4. 이번 범위에서 유지하는 결정

- 메인 히어로, 메인 하단 문의폼, `partnership.html` 문의폼을 변경하지 않습니다.
- 자회사형 장애인 표준사업장 제도 설명을 추가하지 않습니다.
- `location.html` 구조, canonical/공식 URL 체계, 공개 이메일, archive/activities 구조, Production·Netlify 설정을 변경하지 않습니다.
