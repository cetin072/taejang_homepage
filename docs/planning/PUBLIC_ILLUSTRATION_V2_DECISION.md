# 공개 홈페이지 일러스트 V2 결정 기록

상태: **확정**  
기준 Issue: #56, #62  
적용 대상: 태장 공개 홈페이지의 설명용 일러스트

## 목적

일러스트 수를 늘리는 것이 아니라, 처음 방문한 사람이 태장을 더 빨리 이해하도록 실제 사진·HTML/CSS·일러스트의 역할을 구분한다.

## 확정 원칙

1. `1 일러스트 = 1 메시지 = 1 핵심 장면`을 지킨다. 한 장에 과정·장소·설명을 겹쳐 넣지 않는다.
2. 실제 근로자, 제품, 작업장, 활동, 성과처럼 증거가 있는 내용은 실사를 우선한다.
3. 단계, 수치, 연혁, 비교, 구조는 HTML/CSS가 더 명확하면 일러스트로 대체하지 않는다.
4. 이미지 안에는 제목·라벨·숫자·로고·설명 문구를 넣지 않는다. 설명은 HTML이 담당한다.
5. 수채화 톤은 저채도 아이보리·크림·세이지 중심으로 유지하되, 유아적 캐릭터·포토리얼 AI·인포그래픽형 그림은 사용하지 않는다.

## 실사와 일러스트의 경계

실제 사람·제품·사업장·행사·환경정비처럼 방문자가 ‘정말 하고 있는 일인가’를 확인해야 하는 영역은 실사가 우선이다.

반대로 실제 한 장의 사진으로 의미를 전달하기 어렵고, 제목과 함께 보았을 때 한 장면으로 즉시 이해되는 설명 블록에 한해 일러스트를 사용할 수 있다.

따라서 `workplace.html`의 3개 수채화 타일을 유지하더라도 메인 홈페이지의 실제 일터 사진, 활동 기록, 사업 사진을 일러스트로 대체하지 않는다.

## 승인 게이트와 후속

- 새 이미지 생성, 기존 이미지 교체, 새 페이지 배치는 사용자 시각 승인과 공개 승인 확인 후에만 한다.
- 승인된 실제 자산이 없다고 해서 유사한 ‘증거 사진’을 임의 생성하지 않는다.
- Draft PR #57은 V1 스타일·검토 기록으로만 취급하고 현행 구현 기준으로 병합하지 않는다.
- 실제 새 후보가 생기면 페이지·핵심 메시지·한 장면·HTML 설명·실사보다 나은 이유를 별도 Issue에 기록한 뒤 검토한다.
