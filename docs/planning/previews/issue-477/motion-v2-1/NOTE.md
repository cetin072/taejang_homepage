## 네 장면 콘티

1. **0초 / 시작:** 원래 시계와 주변 그림·문장이 이미 보인다. 0–0.6초 방향 제시와 0.6–1.9초 동일 선의 체크 변형은 V2와 같다.
2. **3.4초 / 초점 전달:** 2.3–3.2초 연결선이 카드에 닿고 카드 체크가 진행 중이다. 3.1초부터 중앙 강조가 차분히 낮아진다.
3. **3.9초 / 카드 완성:** 카드 체크가 끝난다. 중앙 확인은 옅고 가늘게 남아 결과 취소로 보이지 않게 한다.
4. **5.2초 / 정적 끝:** 연결은 사라지고 완성된 그림이 남는다. V2의 끝은 별도로 6.8초다. 이후 자동 반복·예약 프레임이 없다.

같은 시각 5.2초 버튼과 각 버전의 최종 프레임 버튼을 구별했다. 길이를 정규화해 핵심 전환 속도를 다르게 보이게 하지 않는다.

## 실제 프레임을 보고 판단한 것

PC·모바일 4장면 및 모바일 연결선 근접 캡처를 확인했다. 3.4초 연결선은 기존보다 굵고 본문과 겹치지 않는다. 마지막 중앙 체크는 급히 사라지지 않고 톤이 완화된다. **중앙 모양 자체가 크기 때문에 여전히 먼저 눈에 들어올 가능성이 있다.** 이번 조정이 충분히 카드로 시선을 넘기는지, 더 짧은 정리가 편안한지는 실제 재생과 사용자 판단이 필요하다. V2.1을 자동으로 우승안이나 ‘전문가 품질 PASS’로 확정하지 않는다.

근접 비교는 실제 390px 뷰포트의 일부를 약 2.4배 확대한 검토용이다. 작은 원본 SVG 부가 라벨을 커졌다고 보고하지 않는다. 핵심 설명은 기존 DOM 본문에 남는다. 최종 중앙 표시의 흰색 배경 대비는 약 4.27:1이나 이것만으로 전체 접근성 적합을 인증하지 않는다.

## 참고 기준·변경 경계

diagram-design의 정적 완결·단일 초점과 motionmaxxing의 인과적 인계·타이밍·실제 렌더 검토 원칙을 V2에 이어 적용했다. 출처 SHA·라이선스·참고 범위는 [V2 제작 기록](../motion-v2/NOTE.md)에 보존했다. 새 런타임·GSAP·AI 이미지·폰트·라이브러리 설치는 없다. 원본 스킬의 G0–G5 도구·전문가 인증을 통과했다고 주장하지 않는다.

현재 결론은 **V2.1 비교안 제작·기술 검증 완료, 디자인 선택 대기**다. 한 번 보고 ‘시간 → 기록 확인 → 출근 카드’를 설명할 수 있는지, 템포가 편한지, 초점이 충분히 전달되는지, 지나치게 조용하거나 일반적인 AI 카드 모션처럼 보이는지를 평가한다. 실제 Android/iOS·보조기술·장애인 직원 이해도는 미확인이다.

A안 개발자 노트 실제 모션, B안·DAILY 확대, 홈페이지 코드 적용·Ready 전환·main 병합·고정 QA 교체·운영 배포·직원앱/DB/Auth/근태 변경은 모두 하지 않았다. HERO 선택 후 후속 범위를 결정한다.

## 재현

기존 Playwright/Chrome과 번들 Python/Pillow만 사용한다.

```powershell
node docs/planning/previews/issue-477/motion-v2-1/build-mockup.cjs
node docs/planning/previews/issue-477/motion-v2-1/check-study.cjs
node docs/planning/previews/issue-477/motion-v2-1/review-browser.cjs
node docs/planning/previews/issue-477/motion-v2-1/serve-review.cjs
```

서버 주소를 확인한 뒤 `make-materials.cjs <baseURL>` 및 `check-interruption.cjs <baseURL>`을 실행하고 `encode-review.py`를 실행한다. 원시 PNG는 captures/로 제외하고 선정 자료만 저장한다. V2 폴더의 원본은 수정하지 않는다.
