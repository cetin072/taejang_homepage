# Pilot H — HERO 모션그래픽 V2 콘티

2026-10-17 · 검토용 작동 시안 · 홈페이지 미구현

기준: Issue #477 [V2 목표](https://github.com/cetin072/taejang_homepage/issues/477#issuecomment-6218271475), 기존 main `7983c988`, PR #478의 정적 기준선. 이번 사용자 요청은 HERO 작동 시안 우선이며 A안 모션 구현은 HERO 평가 뒤 결정한다.

## 이야기와 선택

- 문제: 기존 HERO는 여러 조각이 같은 등장 효과로 나타나 기능 사이의 설명보다 장식이 먼저 보인다.
- 대상: 직원·가족·기업 방문자. 휴대폰에서도 차분히 볼 수 있는 홈페이지 삽화.
- 목표: 출근 기록의 핵심인 ‘기록 → 확인’을 그림의 연속 변화로 읽게 한다. 실제 버튼 조작법이나 서버 처리 과정을 시연하지 않는다.
- 감정: 불필요한 재촉 없이, 기록의 결과를 알아볼 수 있다는 안정감.
- 자산: 기존 휴대폰, 중앙 시계, 출근 카드와 확인 표시, 녹색·베이지·나눔 글꼴. 공지·퇴근과 식물 배경은 정적 문맥으로 유지.
- 색 의미: 녹색은 이번 장면의 ‘기록 확인’에만 움직임으로 집중한다. 배경·서체·휴대폰 크기·페이지 문구는 보존한다.

검토한 서로 다른 연출:

1. 기능 투어: 출근·공지·퇴근을 순서대로 강조 — 기능 세 개를 동등하게 반복하고 필수 순서로 오해할 수 있어 제외.
2. 사용자 의견 말풍선을 휴대폰으로 보내기 — HERO에 없는 새 자산·기획 완료 암시·설명 증가가 필요해 제외.
3. **기존 시계의 선이 확인 표시로 이어지는 한 장면** — 자산을 살리고 한 가지 결과에 집중하므로 선택.

단순히 로고를 바꾸면 다른 앱에도 사용할 수 있는 보편적 은유라는 한계는 있다. 태장 고유성은 기존 삽화·브랜드·현장 피드백의 ‘상태를 명확히’라는 문맥에서 온다. 이 시안을 독창성 검수 완료로 자평하지 않는다.

## 4장면 — 204프레임 / 30fps 기준 / 6.8초

| 장면 | 시간 | 보는 사람이 이해할 것 | 움직이는 것과 인계 | 멈춤·정적 결과 |
| --- | --- | --- | --- | --- |
| 1. 기록의 시작 | 0–0.6초 | 시계가 이야기의 중심임을 알아본다 | 기존 시계 바늘만 짧게 움직여 다음 변화의 방향을 만든다. 배경·폰·카드를 등장시키지 않는다. | 시계와 세 기능은 처음부터 보인다. |
| 2. 기록이 확인으로 | 0.6–2.3초 | 시간 표시에서 확인 표시로 바뀌는 결과를 읽는다 | 시계의 **동일한 3점 선**을 확인 표시로 연속 보간한다. 화면 전환·문자 페이드·가짜 앱 UI는 없다. 변화의 끝은 감속하고 0.4초 읽는 여유를 둔다. | 중앙 확인 표시. 이 장면만 중요도 3, 나머지는 1~2. |
| 3. 확인이 카드에 닿다 | 2.3–4.8초 | 바뀐 표시와 출근 카드의 관계를 따라간다 | 중앙에서 기존 카드 경계까지 녹색 선이 오른각의 부드러운 모서리를 따라 이어진다. 선이 도착한 다음 기존 카드 체크를 그려, 도착과 반응의 순서를 구분한다. | ‘출근 기록’ 문구는 내내 읽히며 체크가 완성된다. |
| 4. 읽는 화면으로 돌아오다 | 4.8–6.8초 | 움직임이 끝나고 전체 기능 소개를 읽는다 | 장식 연결선만 정리된다. 중앙 확인·출근·공지·퇴근은 남는다. 반짝임·바운스·다음 루프 없음. | 약 1초간 읽기 상태 후 재생 종료. 웹에서는 이 최종 정지 상태를 계속 유지. |

PC·모바일은 같은 그림 좌표와 이야기를 사용한다. 휴대폰 그림을 새로 크게 만들거나 별도 섹션을 추가하지 않는다. CTA·설명·하단 섹션의 위치는 기존 HERO와 같다. 모바일에서 SVG 내 글자는 그림의 부가 라벨이며 주요 기능 설명은 원래 DOM 텍스트로 유지된다.

## 원본 교체·보존

- 교체: 독립 목업 HERO에서 원래의 세 요소별 `translateY/opacity` 등장 효과를 중지하고 중앙 시계/출근 카드의 연속 동작으로 대체.
- 보존: 모든 공개 문구, 안내 그림 고지, 원본 SVG의 폰·배경·공지·퇴근, 메뉴·CTA·개인정보 링크. 실제 직원앱은 연결하지 않는다.
- 해석 고지: ‘기록과 확인을 설명하는 연출이며, 실제 앱 화면이나 이용 순서를 뜻하지 않습니다.’를 목업 검토 도구에 둔다. 실제 사이트에 이 문구를 추가하는 결정은 미확정.
- 정적 완결: HTML 원본은 확인 표시가 완성된 최종 그림. JS off/초기 오류/모션 감소/인쇄는 이 상태를 유지한다.
- 제어: 재생/일시정지/다시 보기, 0/50/100% 프레임 확인. 뷰포트 밖·탭 숨김에서 일시정지, 재진입 자동 반복 없음.
- 소리 없음: 업무용 공개 웹의 비청각 접근성과 조용한 사용을 우선한다. 음성·음악 서비스와 유료 API는 사용하지 않는다.

## 참고 기준의 적용 범위

diagram-design의 정적 완결·단일 초점·모션 감소 기준과 motionmaxxing의 동일 물체 인계·의도별 곡선·과잉 강조 제거·실제 렌더 검토를 적용한다. 두 스킬의 런타임은 복사하지 않는다. 영상용 GSAP/3D/새 글꼴/사운드, 영상 속 헤더 금지, 마지막 장면 1.4초 제한을 홈페이지에 기계적으로 이식하지 않는다. 웹은 사용자가 계속 읽을 정지 화면으로 끝나야 한다.

이 콘티는 사용자 평가를 위한 제안이며 ‘전문가 품질 PASS’ 또는 실제 기능 적용·배포 완료 기록이 아니다.
