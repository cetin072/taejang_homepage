## 연출과 실제 자산

선택한 이야기: **시계의 두 선이 확인 표시가 되고, 같은 선의 진행이 기존 출근 카드에 닿아 확인 표시를 완성한다.** 카드 세 개를 같은 fade/slide로 차례로 보여주지 않는다. 시계·휴대폰·기존 출근 카드·공지 그림·퇴근 기호·식물·브랜드 색·글꼴은 기존 HERO에서 가져왔다.

새로 그린 것은 중앙 선의 최종 체크 좌표와 카드까지의 짧은 연결선이다. 중앙 선의 3개 점을 같은 구조로 연속 보간하고, 카드의 원래 체크 선을 그린다. 새 사진·생성형 이미지·가짜 실제 앱 화면·직원 데이터·임의 시간·실적 수치는 없다. 출근 성공을 실제로 확인하는 앱 동작이 아니며, 앱 기능이 배포됐다는 증거로 사용하지 않는다.

유지한 공개 문구: HERO 제목·설명·안내용 그림 고지, 하단 모든 섹션의 본문·날짜·CTA·메뉴·개인정보 링크. 검토 도구의 해설은 공개 본문에 추가하지 않았다. 접근성 B안 및 A안의 실제 모션은 이번 시안에 적용하지 않았다.

- 기준·아이디어만 참고하고 시안 코드는 기존 SVG·CSS와 표준 브라우저 API로 작성했다. 추가 npm 의존성 0개, 새 CDN 스크립트 0개, 실제 앱·DB·외부 API 요청 0개다.
- CSS는 정적 최종 상태·반응형·기존 그림을 소유한다. 보간과 일시정지·재개·정확한 프레임 이동을 위해 작은 단일 `requestAnimationFrame` 컨트롤러를 사용한다. 이 부분은 CSS만으로 정확한 프레임 제어를 맞추는 것보다 단순하다. 재생 종료 시 요청 프레임 0개로 정리한다.

## 장점·한계·남은 결정

- 장점: 같은 선의 변화가 반응으로 이어지고 페이지 길이를 늘리지 않는다. 기존 의미 텍스트를 보존하며 작은 범위에서 재생을 제어한다. 새 런타임 설치가 없다.
- 한계: 작은 웹 삽화라 변화가 절제돼 있다. ‘기록 확인’은 보여주지만 ‘현장 의견을 받아 앱이 개선된다’는 철학을 이 HERO 하나로 모두 설명하지 않는다. 공지·퇴근을 움직이지 않으므로 기능 투어 같은 장면 수를 기대하면 정적으로 느낄 수 있다. 중앙 시계가 최종 체크로 남는 표현이 태장의 브랜드 톤에 적합한지 확인이 필요하다.
- 미확인: 사용자·장애인 직원의 실제 이해도, 실제 Android/iOS·TalkBack/VoiceOver·저성능 기기, 다른 브라우저의 실제 사용성, 홈페이지 hosted UAR. 브라우저 검증이 디자인 수용을 대신하지 않는다.
- **다음 결정:** HERO를 실제로 보고 ‘이야기가 읽히는가 / 템포가 편한가 / 변화가 너무 약하거나 과한가’를 판단한다. 그 결과 뒤에만 A안 모션을 제작한다. B안과 DAILY 모션 추가는 제외했다.
- 재사용 레시피 V1·공통 런타임은 아직 만들지 않았다. 첫 실증의 사용자 수용 전이기 때문이다.
- homepage main 병합·운영 배포·고정 QA 교체·직원앱·DB·Auth·근태 로직 변경은 없다. 이 PR의 수정 범위는 기획 문서와 `docs/planning/previews/issue-477/`의 독립 시안뿐이다.

## 재현

기존 프로젝트 Playwright/Chrome과 번들 Python/Pillow를 사용했다. HTML 생성과 브라우저 QA는 다음 순서다.

```powershell
node docs/planning/previews/issue-477/motion-v2/build-mockup.cjs
node docs/planning/previews/issue-477/motion-v2/review-browser.cjs
node docs/planning/previews/issue-477/motion-v2/make-boards.cjs
python docs/planning/previews/issue-477/motion-v2/encode-review.py
```

`check-shell.cjs`와 `check-interruption.cjs`에는 실행 중인 로컬 서버의 base URL을 첫 인수로 전달한다. GIF 인코딩은 브라우저가 그린 PNG를 묶을 뿐 새 그래픽을 생성하지 않는다. 재생/프레임은 결정적이지만 rAF 측정값·글꼴 로딩 시간은 실행 환경에 따라 달라진다. 원시 캡처는 `.gitignore`로 제외하고 선택한 비교 자료와 측정 JSON만 보관했다.
