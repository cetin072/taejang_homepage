# 테라리움 주문제작 랜딩페이지 V1 — 검토용 초안 (2026-11-10)

## 사용자 요청 및 현재 기획
- 태장 테라리움 제작 의뢰용 별도 랜딩페이지 초안 작성.
- 사용자가 실물 제품 사진을 제공하기 전에는 저장소의 기존 샘플 이미지를 사용하고 실물 주문제작 제품으로 오인시키지 않는다.
- 랜딩페이지 초안을 만들면서 메인과 '하는 일'의 테라리움 제조사업을 개발 중인 사업 영역에서 현재 진행 중인 사업 영역으로 이동한다.
- 직원 테라리움 교육과 식물 관리·DIY 키트·주문제작 기획을 연결한다.
- 고급 제품 중심의 사진·여백 위주 디자인을 유지하고 상세 설명을 과도하게 늘리지 않는다.

## 구현 구조
1. 큰 사진과 짧은 제목: 당신의 공간에 작은 숲을.
2. 기존 샘플 사진 2장: 이미지 교체 위치를 명확히 구분.
3. 공간 인테리어 / 선물 / 기업·기관 주문 상담 가능성.
4. 제작 범위 및 비용·일정은 상담 후 안내.
5. 기존 Netlify Forms의 taejang-inquiry 이름과 입력항목을 재사용. 신규 DB·외부 서비스·결제·예약 없음.

## 2026-11-10 사용자 추가 승인: 메인 반영은 준비 중 표시 유지
- 사용자 요청에 따라 테라리움 상품 카드는 '현재 운영' 섹션 아래에 유지하되, 판매·맞춤 주문제작은 **준비 중**으로 표시한다. 직원 교육 등 현재 활동과 외부 주문제작 개시 상태를 구분한다.
- 메인 및 '하는 일' 카드의 '주문제작 알아보기' 링크는 제거하고 텍스트 '주문제작 안내 준비 중'만 표시한다.
- 서비스·상품 메뉴에 태장 업무수첩과 같은 **비클릭 준비 중 카드**를 추가한다. 제품 페이지 링크는 연결하지 않는다.
- 랜딩페이지 파일은 차후 공개·실물 사진 교체를 위해 보존하며, 메인 링크로 공개하지 않는다. 페이지 URL 직접 접근 자체를 막는 인증 경계는 이번 범위에 없다.
- 이번 명시 승인에 따라 PR 검수 성공 후 main 병합까지 진행한다. Production 즉시 배포 승인은 별도로 다룬다.
