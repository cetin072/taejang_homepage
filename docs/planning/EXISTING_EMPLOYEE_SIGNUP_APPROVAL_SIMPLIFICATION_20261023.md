# 기존 직원 가입 승인 간소화 — 2026-10-23

## 목적
운영총괄의 가입 승인에서 기존 인사카드와 직원앱 계정을 안전하고 빠르게 연결한다. 사용자 요청의 핵심은 미연결 직원 선택 목록 표시와 중복 신원 확인 입력 제거다.

## 확정된 사용자 흐름
1. '기존 직원 연결'을 선택한다(기본값).
2. 계정이 연결되지 않은 **재직·미보관** 직원만 기존 직원 목록에 노출한다. 부서/직책 미배정도 직원 자격을 없애지 않는다.
3. 직원번호·이름·입사일을 표시하고 신청 자료와의 차이가 있으면 강조 안내한다.
4. 담당자가 **'기존 직원번호와 가입 신청자의 신원을 직접 확인했습니다'** 체크박스 하나를 체크한다. 직원번호 수기 재입력 및 추가 불일치 체크박스는 없앤다.
5. '기존 직원 연결 후 가입 승인'을 클릭하면 추가 팝업 없이 기존의 서버 승인 RPC로 계정만 연결한다. 신규 직원 생성 흐름에는 기존 최종 확인 팝업을 유지한다.

## 유지하는 안전 경계
- 화면의 직원번호는 선택한 기존 서버 후보에서 전달하되, 서버는 여전히 UUID와 직원번호 일치 여부를 검증한다.
- 인적사항 불일치 시 서버는 명시 확인 플래그와 사유를 확인하고 감사기록을 보존한다. 동일한 신원 확인 체크박스를 불일치 확인 의사로 전달한다.
- 운영총괄/승인 권한, 역할 배정 제한, 이중 연결 차단, 재직 상태 검사, 계정 상태 및 감사 이력은 서버 기존 계약 그대로다.
- 기존 Employee/Person/직원번호/근태/급여 데이터 변경 또는 신규 생성은 수행하지 않는다.
- 대표이사 승인 확장 등 별도 범위는 다루지 않는다. 기존 Draft PR #505의 후보 목록 수정과 겹치므로 병합 순서 및 migration 변경 순서(이번 파일은 2026-10-23)를 확인한다.

## 배포 경계
본 변경은 코드·테스트·새로운 read-only 후보 조회 함수 정의만 제출한다. 실제 운영 DB migration 적용, 실계정 승인, Production 배포는 별도 승인·검증 후 진행한다.
