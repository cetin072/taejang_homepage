# 직원 복지 자격 등록

2026-11-19 사용자 요청에 따라 직원관리에서 기초생활수급자·차상위계층 여부를 관리한다.

- 구현 선택은 직원 상세의 별도 접이식 ‘복지 자격 보기’이다. 각 항목을 미확인·해당·비해당으로 선택한다. 미확인은 DB NULL로 저장한다.
- 기존 장애정보 접근 검증을 재사용한다. 운영총괄·운영팀장의 실제 역할, 메뉴 접근 및 대상 직원 제한이 동일하게 적용된다.
- 직원 목록과 일반 직원앱 응답에는 자격 값을 포함하지 않는다. 조회·저장 감사 로그에는 실제 자격 값을 기록하지 않는다.
- 저장 실패 시 입력을 보존하며 동시 변경은 revision으로 차단한다. 미확인으로 변경해 잘못 등록한 값을 지울 수 있다.
- 첨부 2025년 안내서에서는 중증장애인 근로자의 기초생활수급자·차상위계층 여부가 출퇴근비용 지원 조건 중 하나로 설명된다. 이번 범위는 직원 정보 등록이며 지원 자격 자동 판정·지원 신청·증빙 업로드는 포함하지 않는다.
- 이 변경의 운영 DB 적용·병합·배포는 후속 승인 대상이다.
