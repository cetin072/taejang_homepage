# 공개 검색·콘텐츠 품질 개선 V1

- 승인: 2026-11-09, 사용자에게 제시한 1~6번 수정안 전체 구현 승인.
- 상태: 구현 후보. main 병합·Production 배포는 별도 단계.
- 기준: AGENTS.md, TAEJANG_PUBLIC_WEB_BRIEF.md, PROMOTION_EMPLOYEE_DASHBOARD_V1.md.

## 구현 범위

1. 회사 소개·사업·협력·방문 페이지의 검색 제목/설명과 OG/Twitter 문구 정합성.
2. 회사 소개는 기존 4칸을 유지하며 소재지, 인증일/번호, 승인된 공동출자기업, 운영/개발 중 사업을 구분하고 근거 페이지로 연결.
3. 협력 FAQ의 기존 6개를 보존하고 승인된 업무 협력 질문 1개 추가.
4. 회사 구조화 데이터의 고정 @id를 소개 페이지 및 정적/동적 자체 Article의 author/publisher에서 재사용.
5. Edge HTML과 JS fallback에서 같은 표시 함수를 사용. 중복 요약은 숨기고 승인 본문은 보존. 링크 자료의 날짜는 홈페이지 등록일로 명시. 원문 행사일·원문 발행일을 추측하지 않음.
6. 외부 원문 소개와 공식 블로그 연결/재게시 페이지는 noindex, follow로 제공하며 Article 작성자를 태장으로 표시하지 않음. 공식 원문 링크와 기존 상세 URL은 유지. 자체 홈페이지 글·별도 영상 설명은 검색 제공 유지. 공개 피드에 본문이 없으므로 검색 제외 판정은 목록/상세에 공통으로 있는 출처/종류/요약만 사용해 사이트맵과 일치시킴.
7. 출처 URL이 기존 승인 content.js의 활동 자료 URL과 정확히 일치하면 해당 공식 활동 기록·활동일·요약으로 연결. 단순 제목/날짜 유사성으로 글을 합치거나 리다이렉트하지 않음. content.js가 활동 데이터의 유일한 원천이며 별도 복제본을 관리하지 않음.

## 범위와 제한

- DB, 발행 원본, 승인 상태, 사진, 개인정보, 원문 제목/본문/날짜의 영구 수정 없음.
- 잘린 원문은 완성된 자체 글로 가장하지 않고 원문 미리보기로 구분. 기존 승인 활동 자료로 확인 가능한 사실만 보강하며, 자료가 없는 글을 AI로 확장하지 않음.
- 원문 기사 작성자·원문 발행일의 사실 확인과 관리자 정정 발행은 원문 확보 및 기존 발행 절차를 통해 수행. 등록일을 행사일로 변경하지 않음.
- Google Search Console·네이버 Search Advisor의 실제 색인·수집·성과 수치는 인증된 관리 화면 확인 전 미확인. 인증 메타태그나 사이트맵 응답만으로 등록/색인을 주장하지 않음.
- llms.txt, 새 서비스/유료 API, 크롤러 허용 범위, 운영 배포 설정, Auth/RLS/migration 변경 없음.
