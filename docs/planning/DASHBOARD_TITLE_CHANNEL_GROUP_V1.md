# 대시보드 제목·공식채널 그룹 정리 V1

상태: 확정
확정일: 2026-09-04

## 목적
업무앱에서 브랜드/역할/화면명이 반복되어 보이는 문제와 공식 블로그·유튜브가 홍보작성의 하위 메뉴처럼 보이는 문제를 정리한다.

## 화면 위계
- 좌측 사이드바 브랜드: `태장 / 업무플랫폼` 유지
- 상단바: 현재 역할명만 표시 (`운영팀장`, `운영총괄`, `홍보직원` 등)
- 상단의 작은 `태장 업무플랫폼` 문구는 제거
- 역할 대시보드 본문 제목은 공통으로 `대시보드`
- 본문 설명은 역할별 우선 업무 문구를 유지
- 점검중 화면에서도 상단 역할명을 유지하고 본문에서 기능명을 표시

## 공식 채널 그룹
홍보직원·운영팀장·운영총괄에게 업무 메뉴와 분리된 `공식 채널` 그룹을 표시한다.

순서:
1. 홈페이지
2. 공식 블로그
3. 공식 유튜브

공식 주소:
- 홈페이지: `../index.html`
- 블로그: `https://blog.naver.com/taejang-official`
- 유튜브: `https://youtube.com/@taejangofficial`

모두 새 탭으로 열며 `noopener noreferrer`를 유지한다.
