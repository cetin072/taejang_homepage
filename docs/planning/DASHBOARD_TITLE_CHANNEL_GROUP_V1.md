# 대시보드 제목·공식채널 그룹 정리 V1

상태: 확정
확정일: 2026-09-04
관련 Issue: #105

## 화면 위계
- 좌측 사이드바 브랜드 `태장 / 업무플랫폼` 유지
- 상단에는 현재 역할명만 표시
- 상단의 작은 `태장 업무플랫폼` 제거
- 역할 대시보드 본문 제목은 공통 `대시보드`
- 역할별 설명 문구는 유지

## 운영팀장 우선순위
1. 대시보드
2. 출근부
3. 홍보 검토
4. 홍보 작성
5. 팀 직원 관리
6. 업무 배정
7. 일정 관리
8. 공지 관리
9. 안내 관리
10. 홈페이지 내용 관리
11. 작업 매뉴얼
12. 공식 채널
13. 신규 사업 기획 · 점검중

## 공식 채널
홍보직원·운영팀장·운영총괄에게 별도 `공식 채널` 그룹을 표시한다.

1. 홈페이지
2. 공식 블로그
3. 공식 유튜브

업무 메뉴와 시각적으로 분리하고 모든 링크는 새 탭으로 연다.

## 권한
표시와 정보구조만 변경하며 Auth/RLS/업무 권한은 변경하지 않는다.
