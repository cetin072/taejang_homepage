# 일일 업무일지 V1

- 새 기록부터 ERP에 작성 및 검색. 과거 PC 파일 이관과 업무수첩 앱 연결은 이 PR 범위가 아닙니다.
- 팀장급 본인 작성·수정, 운영총괄과 대표의 전체 읽기/출력. 역할 미리보기와 일반 근로자 접근 금지.
- 첨부 양식의 기록 번호, 작성일, 작성자, 오전/오후, 세 업무란 및 이사/대표 수기 칸을 유지합니다. 전자결재는 하지 않습니다.
- 저장 후 인쇄, 저장된 기록의 Word(.docx) 다운로드, 브라우저 인쇄의 PDF 저장. 쓰기 시 이전 개정 번호를 대조해 다른 화면의 수정이 유실되는 일을 방지합니다.
- 운영 활성화는 새 DB 마이그레이션과 웹 배포를 함께 계획합니다. 검수에는 합성 업무와 계정만 사용합니다.

## 업무수첩 앱 연동

- ‘내 업무’에서 같은 ERP 일지를 작성·조회합니다. 기존 태장 Auth UUID와 서버의 실제 역할을 확인합니다. 팀장급은 본인 기록을 편집하고 운영총괄·대표는 타인 기록을 읽기 전용으로 봅니다. 역할 미리보기 중에는 접근을 차단합니다.
- ERP와 업무수첩 앱에서 작성일에 겹치는 본인 업무수첩 일정을 조회합니다. 선택한 일정은 미리보기와 사용자의 저장을 거쳐 업무 내용 끝에 추가합니다. ERP가 선택한 일정의 ID와 일정 수정 시각을 확인하고 개정 번호를 대조해 일지와 저장 이력을 함께 처리합니다.
- Word 다운로드와 PDF 저장의 기본 파일명은 작성일_작성자입니다. 예시 파일명은 2026-11-27_김형철.docx입니다.
- 초기 일지 SQL은 운영 DB 이력 20261127035308의 원문과 동일합니다. 저장소의 초기 파일명을 이 버전에 맞췄습니다. 후속 일정 가져오기 SQL은 별도로 검수하고 적용을 승인받습니다.
