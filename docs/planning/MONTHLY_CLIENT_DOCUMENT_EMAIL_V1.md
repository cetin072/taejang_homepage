# 월별 거래처 표준 메일 초안 V1

상태: 확정 (2026-10-01 사용자 최종 요구사항)
상위 기획: MONTHLY_CLIENT_DOCUMENTS_V1.md

## 범위

월별 고용산입 현황·용역비·용역 수행 결과 안내 메일 1종만 자동 생성한다. 회사별 문서 화면의 PDF 받기 옆에 메일 초안을 제공하며 SMTP/Gmail API/자동발송은 추가하지 않는다. 계약변경·소급·재발행과 여러 템플릿/예외 관리자는 제외하고 사용자가 초안을 직접 수정한다.

운영총괄 전용 문서 capability와 동일한 경계를 사용한다. 회사 담당자명·담당자 이메일은 회사 기본 설정에 저장하고 기본 인사말에 이름을 강제로 넣지 않는다. 실제 이메일 주소를 테스트 fixture나 공개 저장소에 넣지 않는다.

## 데이터 계약과 문구

문서의 선택 월, 회사, 수행일/장소, 안전교육, 활성 추가 프로그램 및 **동일 calculation module의 결과**를 받는다. 메일 모듈은 총 산입·지분율·적용 인원·공급가액·VAT 포함 합계·단가를 계산하거나 보정하지 않는다. 회사 ID와 기준월이 다른 계산 결과는 거부해 회사/월 혼합을 막는다. PDF 모듈의 파일명을 그대로 첨부 목록에 표시한다.

표준 제목은 기존 제목 자료가 아직 없어 사용자 예시인 [태장] YYYY년 M월 장애인 고용산입 현황 및 용역 수행 자료 송부를 사용한다. 제목/본문 모두 최종 수정 가능하다.

표준 본문은 사용자 제공 인사말·1/2/3항·세금계산서 안내·감사 인사를 유지한다. 추가 프로그램이 없으면 지역사회 환경정비 용역과 안전교육 문장만 출력한다. 야외는 야외 현장 안전교육, 실내 영상은 실내 영상 안전교육으로 표시한다. 활성 프로그램은 제공된 이름을 사용하며 프로그램 종류의 효과를 추정하지 않는다. 사용자 제공 환경보호 캠페인 버스킹은 확인된 시민 대상 인식 개선 표현을 사용한다.

수행일은 YYYY-MM-DD를 엄격히 확인하고 UTC 기준 달력 연산으로 요일을 결정한다. 현장사진 첨부 OFF는 사진 안내/ESG 활용 문단과 사진 ZIP 첨부 목록을 함께 제거한다. ON은 두 내용을 포함한다. ZIP 자체 생성이나 파일 첨부는 이번 메일 기능의 범위가 아니다.

## 편집과 갱신 UX 계약

- 회사/월/문서 값 변경은 현재 계산 결과를 이용해 새로운 자동 초안을 만든다.
- 사용자가 편집한 제목/본문을 자동 갱신으로 조용히 덮어쓰지 않는다. 편집 내용이 있으면 최신 문서 데이터와 달라졌음을 표시하고 새 자동 초안 적용 여부를 선택하게 한다.
- 이전 회사의 편집 내용을 새 회사에 재사용하지 않는다. 회사별 편집을 구분하며 변경 전에 미복사 편집을 보존한다.
- 제목 복사/본문 복사 버튼을 제공한다. Clipboard 실패는 성공으로 표시하지 않고 선택 후 직접 복사할 수 있게 한다.
- 화면 입력과 PDF와 메일의 금액 일치는 실제 문서 계산/UI 연결 후 검증한다. 독립 메일 모듈 테스트만으로 이 항목을 PASS로 처리하지 않는다.
