## 2. 확정 스타일

### 전체 인상

- 연하고 부드러운 **수채화 일러스트** 느낌
- 따뜻하고 친근하지만 유아적이거나 만화적으로 과장되지 않음
- 기업 홈페이지에 어울리는 차분한 편집 일러스트 톤
- 실사처럼 속이는 AI 사진이 아니라 명확한 **설명용 일러스트**로 보이게 함

### 색감

- 저채도 중심
- 아이보리·크림·연한 베이지 배경
- 세이지·올리브·부드러운 그린을 주색으로 사용
- 필요한 경우 연한 브라운·회청색·살구색 정도를 보조색으로 사용
- 선명한 원색, 과도한 대비, 네온 계열 금지

### 질감·선

- 종이에 물감이 살짝 번지는 듯한 옅은 수채화 질감
- 가장자리가 지나치게 딱딱하지 않게
- 선은 가늘고 부드럽게
- 강한 벡터 아이콘, 3D 렌더, 플라스틱 질감, 포토리얼 표현 금지

### 사람 표현

- 자연스러운 한국인 성인 중심
- 표정과 동작은 편안하고 업무 장면에 맞게
- 지나치게 귀엽거나 캐릭터화하지 않음
- 장애를 상징물처럼 과장하거나 동정적으로 표현하지 않음
- 사람의 존엄성과 실제 업무의 성격을 우선

### 화면 구성

- 넓은 여백과 낮은 시각 밀도
- 한 장에 메시지 1개가 우선
- 여러 장면이 필요한 경우 좌→우로 자연스럽게 흐르도록 구성
- 홈페이지 삽입을 고려해 PC·모바일 크롭에서도 핵심 장면이 남도록 주요 피사체를 중앙부에 배치
- 이미지 자체에 긴 문장이나 설명 텍스트를 넣지 않음
- 필요하면 작은 상징·사물 수준은 허용하되, 본문 텍스트는 HTML에서 제공

## 3. 사용 원칙

### 실사 유지 영역

실제 운영과 사실을 증명해야 하는 곳은 실사 사진을 우선합니다.

예:
- 실제 작업 현장
- 근로자 작업 모습
- 대표이사 사진
- 실제 제품
- 환경정비 등 수행 실적
- 사업장·방문 정보

### 일러스트 활용 영역

개념, 구조, 관계, 방향, 확장 흐름을 설명하는 곳에 사용합니다.

예:
- 사업 구조
- 협력 구조
- 농업·자연에서 민화와 제품으로 이어지는 흐름
- 하나의 민화 도안이 여러 제품으로 확장되는 관계
- 회사의 역할과 가치 연결

### 인포그래픽 활용 영역

숫자, 단계, 공정, 비교처럼 정보 전달이 우선인 경우는 CSS/간결한 인포그래픽을 사용합니다.

#### B. 하나의 민화 도안 → 다양한 제품

- 기업 굿즈

`참여기업 4개사 → 태장 → 사람에게 맞는 직무 → 실제 사업과 일자리`

주의:
- 지분율·계약관계·법적 혜택을 추정하거나 표현하지 않음
- 제도 홍보물이 아니라 회사 구조와 역할을 설명하는 수준

## 6. 제작·적용 절차

1. 기획방에서 일러스트 생성
2. 사용자 시각 승인
3. 승인된 이미지만 저장소 자산으로 추가
4. Codex가 해당 페이지에 배치
5. PC/mobile, alt, 크롭, 시각적 균형 검수
6. Draft PR → Preview → 사용자 승인 → 병합

Codex가 임의로 다른 스타일의 일러스트를 생성하거나 교체하지 않습니다.

## 8. 1차 적용 범위 변경 — 2026-08-27

사용자 결정에 따라 첫 실제 페이지 적용은 **A와 B 두 장만** 진행합니다.

- A: 사용자 시각 승인 완료 / 원본 확보 완료
- B: 사용자 시각 승인 완료 / 원본 확보 완료
- C (`about.html` 구조 설명 일러스트): 이번 적용에서 제외하고 후속 기획으로 연기

따라서 기존의 “A/B/C 모두 승인된 뒤 구현” 게이트는 폐기합니다. 현재 구현 게이트는 **A/B 승인 자산 확보 완료 → `why-minhwa.html`에 두 장 적용 → Draft PR/Preview 검수 → 사용자 승인 후 병합**입니다.

`about.html`은 이번 구현에서 변경하지 않습니다. C는 나중에 별도 기획·제작·사용자 승인 후 별도 Issue/PR로 진행합니다.
