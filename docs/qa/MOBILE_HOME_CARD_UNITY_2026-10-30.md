# 직원앱 홈 카드 디자인 통일

## 범위와 구현

기준 main: `a0828ac0f986f04b91ed307bfe9c5eb2a505a775`.
대상은 `mobile/`의 태장 직원앱이며 업무수첩 앱은 대상이 아니다.

- 출퇴근 카드는 기존 짙은 녹색·큰 버튼·상태 문구를 유지했다.
- 공지 제목·최신 3건·로딩/빈 상태·오류 재시도·전체보기를 하나의 밝고 선명한 하늘색 `#4db5d3` 카드로 감쌌다. 출퇴근·플랫폼 카드와 모서리 28, 가로/세로 내부 여백 22/24를 맞췄다. 높이는 내용을 따른다.
- 개별 공지는 기존 흰색 라운드 카드, 2줄 제목과 말줄임, 전체 제목 접근성 라벨·상세 경로·읽음 표시를 그대로 재사용한다.
- 빈 상태는 ‘새 공지가 없어요.’, 로딩은 ‘공지 확인 중…’, 목록 이동은 ‘전체보기 →’로 줄였다. 전체보기의 접근성 라벨은 ‘전체 공지 보기’를 유지한다.
- 기존 플랫폼 카드의 노출 조건·비활성 조건·연결 함수를 유지하고 제목을 ‘플랫폼 바로가기’, 연결 중 문구를 ‘연결 중…’으로 줄였다. 제목 25pt·중앙 정렬로 출퇴근의 31pt 주 행동보다 낮은 강조를 준다.
- 홈 ScrollView의 `space-between`을 제거하고 공식 채널 링크를 콘텐츠 뒤 24pt 간격으로 배치해 불필요하게 벌어지는 빈 공간을 줄였다. 카드 사이 14pt는 유지한다.

## 남은 검수 / 완료로 주장하지 않는 항목

- 이 환경에는 adb/Android emulator가 없어 실제 Android 실행·출퇴근 조작을 검수하지 못했다. 운영 근태를 QA 데이터로 저장하지 않았다.
- 별도 Chromium 프로세스 실행은 socket `Operation not permitted`로 실패했고, 제공 브라우저의 초기 진입도 읽기 전용 환경 오류로 실패했다. 실행 제한을 우회하지 않았다. 준비한 DOM 변환 합성 fixture는 브라우저가 시작되지 않아 실행되지 않았다.
- 따라서 320/390px·큰 글씨의 픽셀 배치, 화면 전후 캡처, 실제 기기 공지·플랫폼 이동은 **미검증**이다. mock 검사·색상 계산을 해당 검수의 PASS로 대신하지 않는다.
- Draft 유지. 사용자 화면 수용 검수 준비 완료 또는 전체 CI green으로 보고하지 않는다. main 병합·정식 배포·Play 제출은 별도 승인 대상이다.

## 색상 후속 수정

사용자가 옅은 파스텔 색상이 아쉽다고 피드백해 공지 바깥 카드를 짙은 청색으로 변경했다. 제목/전체보기는 흰색, 보조문구는 밝은 청회색, 오류는 밝은 붉은색으로 대비를 맞췄다. 흰색 개별 공지 카드와 기존 출퇴근 녹색은 유지했다. 색상 수정 후 관련 61개 검사와 TypeScript·diff 검사를 다시 통과했다. 실제 캡처가 아닌 코드 참고 예상 이미지를 갱신했으며 실기 검수는 여전히 미완료다.

## 색상 최종 조정 — 밝은 하늘색

출근과 공지가 모두 어두워 보인다는 사용자 피드백으로, 앞선 짙은 청색 안을 밝고 선명한 하늘색 `#4db5d3`으로 대체했다. 옅은 파스텔 대신 채도를 유지하고, 제목·안내·전체보기는 짙은 `#143d4b`, 오류는 `#672318`로 바꿨다. 출근의 짙은 녹색·흰색 개별 공지는 유지한다. 문구/레이아웃/기능 변경은 없다. 관련 61개 검사·TypeScript·diff 검사 재실행. 이미지는 실제 앱 캡처가 아닌 예상 시안이며 기기 검수 미완료 상태를 유지한다.
