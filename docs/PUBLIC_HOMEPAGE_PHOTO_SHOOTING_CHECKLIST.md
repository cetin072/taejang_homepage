# 태장 공개 홈페이지 사진 촬영 체크표

## 1. 사용 방법

이 문서는 홈페이지에 넣을 사진을 촬영·수집할 때 사용하는 실무 체크표입니다.

- 처음부터 PHOTO 01~08과 최신 소식 카드 수에 맞춰 사진 수를 제한하지 않습니다.
- 각 장면마다 가로 사진을 중심으로 여러 구도와 거리를 확보합니다.
- 원본은 공유 드라이브에 보관하고, 공개 승인된 최종 파일만 홈페이지 저장소로 옮깁니다.
- 얼굴이 보이는 사진은 촬영 가능 여부와 홈페이지 공개 가능 여부를 별도로 확인합니다.
- 송장, 이름표, 전화번호, 주소, 근태자료, 상담자료, 거래처 문서가 보이는 사진은 사용하지 않습니다.

## 2. 촬영 우선순위

### 1순위 — 메인 화면에 직접 필요한 사진

- PHOTO 01 메인 대표사진
- PHOTO 02 민화 작업
- PHOTO 03 환경·사회공헌 활동
- PHOTO 04~06 태장의 일터
- PHOTO 08 대표이사 사진

### 2순위 — 회사소개와 소식 대표사진에 필요한 사진

- PHOTO 07 회사소개 대표사진
- 각 소식·기록 글의 대표사진 (메인 최신 3개 카드에 자동 반영)

### 3순위 — 콘텐츠 소식에 반복 활용할 보조사진

- 민화 작업의 손·도구·작품 세부 장면
- 포장·검수의 준비·작업·완료 장면
- 사업장 전경과 정돈된 작업공간
- 안전교육, 환경정비, 행사 준비 장면

소식 대표사진은 각 콘텐츠의 `thumbnail`으로 관리합니다. 메인 최신 3개 카드는 공개일 최신순으로 이 대표사진을 자동 표시하며, PHOTO 09~11 고정 슬롯이나 별도 업로드 대상은 사용하지 않습니다.

최소 후보 수는 최종 사용 장수가 아니라 촬영 단계에서 확보할 권장 수량입니다. 같은 장면도 거리, 방향, 인물 위치를 바꾸어 촬영합니다.

## 4. 현장 촬영 순서

1. 촬영 전에 작업대와 배경을 정돈합니다.
2. 이름, 주소, 전화번호, 송장, 직원자료, 거래문서가 보이지 않는지 확인합니다.
3. 먼저 인물이 없는 공간과 작업물 사진을 확보합니다.
4. 공개 동의가 확인된 인물만 포함해 전체 장면을 촬영합니다.
5. 같은 장면을 넓게, 중간 거리, 가까이에서 각각 촬영합니다.
6. 가로 사진을 기본으로 하고 필요한 경우 세로 사진도 추가합니다.
7. 촬영 직후 흐림, 눈 감음, 개인정보 노출을 확인하고 필요한 장면을 다시 촬영합니다.

## 5. 사진 공개 상태 기록

공유 드라이브 또는 사진 목록표에서 각 파일에 다음 상태를 기록합니다.

| 항목 | 기록값 예시 |
| --- | --- |
| 파일명 | `2026-08-12_민화작업_001.jpg` |
| 촬영일 | `2026-08-12` |
| 촬영 내용 | 민화 작업대와 손 중심 |
| 후보 슬롯 | PHOTO 02, CONTENT PHOTO |
| 얼굴 노출 | 없음 / 있음 |
| 홈페이지 공개 동의 | 확인 / 미확인 / 사용 금지 |
| 외부인 포함 | 없음 / 있음 |
| 개인정보 노출 | 없음 / 수정 필요 / 사용 금지 |
| 작품·로고 권리 | 확인 / 미확인 |
| 상태 | 원본 / 1차 후보 / 최종 선정 / 보류 |
| 크롭 메모 | 모바일에서 오른쪽 인물 유지 |
| 대체 텍스트 초안 | 민화 도안을 채색하는 작업자의 손과 작업대 |

`미확인` 사진은 홈페이지 미리보기에도 올리지 않습니다.

## 6. 공유 드라이브 폴더와 파일명

권장 폴더 구조:

```text
태장 홈페이지 사진
├─ 00_촬영가이드
├─ 01_원본사진
├─ 02_1차후보
├─ 03_최종선정
├─ 04_홈페이지용_변환본
└─ 99_보류
```

권장 파일명:

```text
YYYY-MM-DD_장면명_순번.jpg
```

예시:

```text
2026-08-12_민화작업_001.jpg
2026-08-12_포장작업_001.jpg
2026-08-12_일터전경_001.jpg
2026-07-24_환경정비_001.jpg
2026-08-12_대표이사_001.jpg
```

파일명에는 직원 이름, 장애정보, 건강정보를 넣지 않습니다.

## 7. 최종 홈페이지용 변환 기준

| 용도 | 긴 변 권장 크기 | 형식 | 로딩 기준 |
| --- | ---: | --- | --- |
| 메인 히어로 | 1600~2000px | WebP 우선 | 첫 화면이므로 우선 로딩 |
| 섹션 큰 사진 | 1200~1600px | WebP 우선 | 지연 로딩 가능 |
| 카드 사진 | 800~1200px | WebP 우선 | 지연 로딩 |
| 대표이사 사진 | 1000~1400px | WebP 우선 | 페이지별 지연 로딩 |

- 원본 사진은 덮어쓰지 않습니다.
- 홈페이지용 변환본에서만 크기, 밝기, 수평, 크롭을 조정합니다.
- 피부나 신체를 과도하게 보정하지 않습니다.
- 사진 위치정보 등 불필요한 메타데이터는 제거합니다.
- 최종 파일은 모바일과 PC에서 모두 확인한 뒤 저장소에 반영합니다.

## 8. 공개 직전 최종 확인

- [ ] PHOTO 01~08과 각 공개 소식의 대표사진이 현재 문구와 일치한다.
- [ ] 모든 인물의 홈페이지 공개 가능 여부를 확인했다.
- [ ] 외부인·방문객·아동이 포함된 사진의 공개 권한을 확인했다.
- [ ] 송장, 이름표, 전화번호, 주소, 모니터, 상담자료가 보이지 않는다.
- [ ] 기업 로고와 제품 포장이 승인되지 않은 방식으로 노출되지 않는다.
- [ ] 인증서 원본은 공개 가능한 정보만 보인다.
- [ ] 모바일 크롭에서 얼굴·손·작품의 핵심 부분이 잘리지 않는다.
- [ ] 각 사진에 의미에 맞는 대체 텍스트가 있다.
- [ ] 최종 파일 용량과 형식을 확인했다.
- [ ] 공식 공개 모드에서 PHOTO 번호와 제작 안내를 숨겼다.
