# 홈페이지 사진 공개동의 및 촬영 당일 운영안

이 문서는 태장 공개 홈페이지에 사용할 사진·영상의 촬영, 공개동의, 현장 안내와 사후 관리를 위한 실무안입니다.

> 촬영에 참여했다는 사실만으로 홈페이지 공개에 동의한 것으로 처리하지 않습니다. 촬영 가능 여부와 외부 공개 가능 여부를 구분해 확인합니다.

이 문서는 내부 운영용 초안입니다. 실제 서명 양식으로 사용하기 전 회사의 개인정보 담당자 또는 법률 전문가가 보유기간·담당자·사용 채널을 최종 확인합니다.

### 수집·이용 안내

| --- | --- |
| 목적 | 태장 공식 홈페이지의 회사소개, 일터 소개, 활동 기록 및 공식 홍보자료 제작 |
| 항목 | 사진·영상 속 얼굴, 신체 일부, 음성 등 개인을 알아볼 수 있는 정보 |
| 원본·후보 보유기간 | 촬영일로부터 1년 이내. 최종 선정되지 않은 파일은 기간 내 삭제 |
| 최종 게시본 이용기간 | 해당 게시물의 공개 종료 또는 동의 철회 시까지 |

| 동의 거부 | 동의하지 않아도 근무, 임금, 업무배치, 평가 등에 불이익이 없음 |
| 철회 방법 | 이메일 또는 전화로 철회 요청. 확인 후 신규 사용을 중단하고 공개본과 보관본을 정리 |

장애·건강정보, 상담내용, 근태자료와 같은 민감한 정보는 이 동의로 수집하거나 공개하지 않습니다. 사진 배경에 이러한 정보가 보이면 해당 사진은 사용하지 않습니다.

- [ ] 사진·영상 촬영에 동의합니다.

- [ ] 태장 공식 SNS·블로그·유튜브 게시에 동의합니다.
- [ ] 보도자료 또는 협력기관 홍보자료 제공에 동의합니다.
- [ ] 얼굴 전체 공개는 원하지 않으며 손·뒷모습·원거리 장면만 허용합니다.
- [ ] 촬영과 외부 공개에 동의하지 않습니다.

## 2. 직원에게 전달할 촬영 당일 안내문

### 단체 채팅 공지용

```text
[홈페이지 사진 촬영 안내]

회사 홈페이지에 사용할 일터·민화 작업·환경활동 사진을 촬영할 예정입니다.

촬영 참여와 홈페이지 공개는 선택사항이며, 동의하지 않아도 근무나 업무배치에 불이익이 없습니다.
얼굴 공개를 원하지 않는 경우 손, 작업물, 뒷모습 중심으로 촬영할 수 있습니다.

촬영 전 담당자가 공개 범위를 확인하겠습니다.
작업대의 이름표, 송장, 전화번호, 직원자료와 개인 물품은 미리 정리해 주세요.

촬영일: __________
담당자: __________
문의: info@taejang.co.kr / 055-293-8626
```

### 촬영 직전 30초 안내

```text
오늘 사진은 태장 홈페이지의 회사소개와 활동 기록에 사용할 예정입니다.
사진 촬영이나 얼굴 공개를 원하지 않으면 지금 말씀해 주셔도 되고, 손이나 뒷모습만 촬영할 수도 있습니다.
동의하지 않아도 불이익은 없습니다.
촬영 후에도 공개 전에 제외를 요청할 수 있습니다.
```

### 이해하기 쉬운 짧은 안내

```text
오늘 회사 사진을 찍습니다.
얼굴이 나오는 것이 싫으면 말해 주세요.
얼굴 없이 손이나 작업물만 찍을 수 있습니다.
사진을 안 찍어도 불이익은 없습니다.
```

## 3. 촬영 담당자 1장 체크리스트

### 촬영 전

- [ ] 오늘 촬영 목적과 게시 채널을 설명했다.
- [ ] 촬영 가능 여부와 홈페이지 공개 가능 여부를 따로 확인했다.
- [ ] 동의하지 않은 사람을 별도로 표시하되 공개 파일명에 이름을 기록하지 않았다.
- [ ] 작업대의 이름표, 송장, 주소, 전화번호, 근태자료, 상담자료를 치웠다.
- [ ] 모니터 화면, 화이트보드, 거래처 문서와 제품 라벨을 확인했다.
- [ ] 외부인·방문객·미성년자의 별도 동의를 확인했다.
- [ ] 기업 로고와 작품의 공개 가능 범위를 확인했다.

### 촬영 중

- [ ] 인물이 없는 공간과 작업물 사진을 먼저 촬영했다.
- [ ] 얼굴 공개 미동의자는 프레임에 들어오지 않게 했다.
- [ ] 손·뒷모습·원거리 촬영 요청을 지켰다.
- [ ] 같은 장면을 넓게, 중간 거리, 가까이에서 촬영했다.
- [ ] 가로 구도를 기본으로 하고 모바일 크롭 여백을 남겼다.
- [ ] 안전장비와 실제 작업 절차가 바르게 보이는 장면만 촬영했다.
- [ ] 장애나 건강상태를 부각하거나 개인을 불편하게 만드는 장면을 연출하지 않았다.

### 촬영 직후

- [ ] 흐림, 눈 감음, 잘못된 자세를 확인했다.
- [ ] 개인정보·문서·차량번호·모니터 화면 노출을 확대해 확인했다.
- [ ] 파일명을 `YYYY-MM-DD_장면명_순번.jpg` 형식으로 정리했다.
- [ ] 동의 상태가 미확인인 파일은 `99_보류`로 이동했다.
- [ ] 원본은 공유 드라이브에 보관하고 공개 후보만 `02_1차후보`로 복사했다.
- [ ] 공개동의서와 사진 파일을 같은 공개 폴더에 보관하지 않았다.

## 4. 사진별 동의·공개 관리대장

공유 드라이브의 제한된 관리 폴더 또는 별도 관리표에서 다음 항목을 기록합니다.

| 항목 | 기록 예시 |
| --- | --- |
| 파일명 | `2026-08-12_민화작업_001.jpg` |
| 촬영일 | `2026-08-12` |
| 촬영 장면 | 민화 채색 작업 |
| 인물 식별 코드 | `P-003`, 이름은 별도 제한 문서에서만 관리 |
| 촬영 동의 | 확인 / 미확인 / 거부 |
| 홈페이지 공개 | 허용 / 불가 / 얼굴 제외 조건부 허용 |
| SNS 공개 | 허용 / 불가 |
| 보도자료 제공 | 허용 / 불가 |
| 외부인·미성년자 | 없음 / 별도 동의 확인 / 사용 불가 |
| 개인정보 노출 | 없음 / 수정 필요 / 사용 불가 |
| 후보 슬롯 | PHOTO 02 / CONTENT PHOTO |
| 게시 위치 | 메인 / 회사소개 / 활동 상세 |
| 철회 요청 | 없음 / 요청일 / 조치 완료일 |
| 상태 | 원본 / 후보 / 최종 선정 / 게시 중 / 삭제 |

관리대장에는 장애 유형, 건강정보, 상담내용을 기록하지 않습니다.

## 5. 동의 철회 요청 처리

1. 요청자의 성명과 대상 사진을 확인합니다.
2. 홈페이지·SNS 등 현재 공개 위치를 확인합니다.
3. 신규 게시와 재사용을 즉시 중단합니다.
4. 공개 페이지에서 해당 사진을 내리거나 인물을 식별할 수 없게 교체합니다.
5. 공유 드라이브의 후보·변환본·최종본을 확인해 삭제 또는 사용 금지 상태로 변경합니다.
6. 관리대장에 요청일, 처리일, 처리 내용을 기록합니다.
7. 검색엔진이나 외부 플랫폼의 임시 저장본은 즉시 사라지지 않을 수 있음을 요청자에게 설명합니다.

## 6. 운영 원칙 요약

- 촬영 동의와 외부 공개 동의는 별개입니다.
- 동의하지 않아도 불이익이 없어야 합니다.
- 홈페이지, SNS, 보도자료는 채널별로 선택하게 합니다.
- 공개동의가 미확인된 사진은 Deploy Preview에도 올리지 않습니다.
- 얼굴 공개를 원하지 않는 사람은 손·작업물·뒷모습 중심으로 촬영합니다.
- 사진과 동의서는 분리 보관하고 접근 권한을 최소화합니다.
- 공개 목적이 끝나거나 동의가 철회되면 더 이상 사용하지 않습니다.
