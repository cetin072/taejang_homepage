# Issue #181 Deploy Preview 실기기 체크리스트

## 홍보팀장

- 최종 역할별 UX 검수는 실제 홍보팀장 계정으로 확인한다. 운영총괄의 역할 미리보기는 권한 빠른 점검용이며 최종 화면 합격 기준으로 쓰지 않는다.
- 사이드바 홍보 영역에 `홍보 관리`, `홍보 작성`이 중심으로 보이는지 확인
- 별도 `홍보 글 관리`/`승인 완료·미발행 글 관리` 중복 동선이 홍보팀장 화면에 남지 않는지 확인
- 홍보 관리 카드에서 `미리보기`, `직접 수정`, `삭제`, `보완 요청`, `승인`, `운영총괄 상신`을 바로 사용할 수 있는지 확인
- 삭제 시 사유 입력을 요구하는지 확인
- 삭제 후 화면에서 사라지고 운영총괄 복구 대상에는 남는지 확인
- 이미 공개 이력이 있는 글에는 미발행 직접 삭제가 적용되지 않는지 확인

## 글 종류와 연결 자료 분리

- `태장 소식 (홈페이지)`을 선택한 상태에서도 `연결 자료`와 `연결 링크`가 계속 보이는지 확인
- `보도자료`를 선택한 상태에서도 `연결 자료`와 `연결 링크`가 계속 보이는지 확인
- `태장 소식` + `태장 공식 블로그` 링크 조합을 저장할 수 있는지 확인
- `태장 소식` + `태장 공식 유튜브` 링크 조합을 저장할 수 있는지 확인
- `보도자료` + `태장 홈페이지` 링크 조합을 저장할 수 있는지 확인
- 링크를 입력한 뒤 글 종류를 바꿔도 URL과 선택한 연결 자료가 사라지지 않는지 확인
- 기존 링크가 있는 글을 수정·보완한 뒤 저장해도 링크가 의도치 않게 제거되지 않는지 확인
- 연결 링크 없이 저장할 때는 연결 자료가 `none` 상태로 남는지 확인

## 링크 불러오기

- 공식 블로그/홈페이지/유튜브/외부 기사 HTTPS 링크 입력 후 `링크 정보 가져오기` 1회 클릭
- 제목, 요약, 본문, 대표이미지 중 가져올 수 있는 값이 채워지는지 확인
- 이미 직접 입력한 제목/본문을 덮어쓰지 않는지 확인
- `외부 기사·자료`는 원문 전체를 본문에 자동 복사하지 않고 태장 측 소개·요약을 직접 작성하도록 안내하는지 확인
- 자동 추출이 막힌 링크에서 직접 제목/본문을 입력해 저장·승인 요청이 가능한지 확인
- 실패 문구가 수동 작성 가능 여부를 명확히 안내하는지 확인

## 게시 희망일

- 게시 희망일 없음 또는 오늘 날짜: 최종 승인 시 즉시 공개되는지 확인
- 미래 날짜: 최종 승인 시 `게시 예정`으로 남고 해당 날짜 00:00 한국시간 이후 공개되는지 확인
- 승인 버튼이 상황에 따라 `승인·공개`, `승인·예약`, `승인·다음 검토`로 구분되는지 확인

## 일반직원 GPS

- 위치권한 허용 상태에서 출근/퇴근 성공 확인
- 실내/초기 저정확도 상태에서 즉시 실패하지 않고 위치 정확도를 더 기다리는지 확인
- 충분한 정확도가 확보되면 기록이 진행되는지 확인
- 최종적으로 정확도를 확보하지 못하면 기존 `LOCATION_UNCERTAIN` 안내/예외 흐름이 유지되는지 확인
- 반경 밖, 권한 거부, 네트워크 실패, 이미 등록됨 메시지가 서로 구분되는지 확인
- 버튼 연타로 중복 기록이 생기지 않는지 확인

## 안전 회귀

- 60m geofence 유지
- 서버시간 유지
- 공개 콘텐츠 revision/audit 보존
- 운영총괄 복구권한 유지
- 외부 링크 metadata 보안 경계(HTTPS/SSRF/redirect/size/timeout/quota) 유지
- 급여/지원사업 레이더 기능 변경 없음
