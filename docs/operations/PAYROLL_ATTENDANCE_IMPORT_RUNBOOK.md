# 태장 급여·근태 — 출퇴근 Excel 자동 Import 운영서

기획 기준: `docs/planning/PAYROLL_ATTENDANCE_ACCURACY_MVP_V1.md`  
Issue: #111

## 목적

직원이 월별로 관리하는 `태장 출퇴근부 ... .xlsx`를 급여·근태 Google Sheet의 `출퇴근원본`으로 자동 변환한다.

이 단계에서는 **출퇴근 시각을 급여 반영시간으로 자동 확정하지 않는다.** 원본을 구조화하고 예외검출 기반을 만드는 것이 목적이다.

## 현재 연결값

Google Sheet `설정` 탭에서 관리한다.

- `B10`: 대상연도
- `B11`: 대상월
- `B27`: 출퇴근부 Drive 폴더 ID
- `B28`: 출퇴근 파일명 기준 문자열
- 대상 Raw 탭: `출퇴근원본`
- 회귀검증 탭: `가져오기검증`

실제 파일 ID·폴더 ID나 개인정보 값은 공개 GitHub 문서에 반복 저장하지 않는다.

## Import 흐름

1. `설정`의 대상연도·월을 읽는다.
2. 지정 Drive 폴더에서 대상월에 맞는 최신 `.xlsx`를 찾는다.
3. 원본 Excel 자체는 변경하지 않는다.
4. Excel을 임시 Google Sheet로 변환한다.
5. 대상월 시트에서 A~F 인사 설명열은 근태 Raw로 복제하지 않는다.
6. G열부터 이어지는 날짜별 `[출근, 퇴근]` 쌍만 읽는다.
7. `출퇴근원본`에 아래 정보를 기록한다.
   - source_key
   - 원본파일/시트/행
   - 성명 원본
   - 근무일
   - 출근 원본
   - 퇴근 원본
   - 상태 원본
   - 수기 표시
   - 가져온 시각/사용자
   - 원본 파일 ID
8. 동일 원본파일+시트 재가져오기는 기존 snapshot을 교체해 중복을 만들지 않는다.
9. 임시변환 파일만 휴지통으로 보낸다.
10. `근태정규화`와 `근태예외`가 결과를 이어서 판정한다.

## 정확성 보호

- 근무일은 문자열이 아닌 Google Sheets `Date` 값으로 저장한다.
- 원본 출퇴근 값은 `getDisplayValues()`로 읽어 사람이 본 표기를 보존한다.
- `월차`, `결근`, `공휴일/대체공휴일`, `중도퇴사`, `수기` 표기를 원본 상태로 유지한다.
- 현재 원본에 존재하는 `8원 10일` 같은 날짜 헤더 오탈자는 파싱할 때만 허용하며 원본 헤더는 비고에 그대로 남긴다.
- 생년월일·성별·장애정보는 근태 Raw로 복사하지 않고 별도 민감 인사정보 저장소에서 관리한다.
- 주민등록번호·장애 관련 번호·카드번호는 이 Import 코드에서 다루지 않는다.

## 8월 익명 Golden Import 기준

실제 `태장 출퇴근부 08월.xlsx`를 로컬 구조검사한 기준이다. 개인 이름·생년월일·장애정보는 GitHub에 저장하지 않는다.

- 대상 시트: `8월`
- 이름이 있는 근로자 행: 23
- 날짜 `[출근, 퇴근]` 쌍: 21
- 예상 Raw 행: **483**
- 원본 상태에 `월차`가 포함된 셀쌍: 12
- 원본 상태에 `결근`이 포함된 셀쌍: 4
- 원본 상태에 `공휴일/대체공휴일`이 포함된 셀쌍: 2
- `수기` 표기가 포함된 셀쌍: 8

Google Sheet의 `가져오기검증` 탭은 위 5개 핵심 집계를 자동 비교한다. Import 전에는 `대기`, 실제 원본이 들어오면 각 항목을 `PASS`/`FAIL`로 판정한다.

Apps Script 첫 실전 실행 후 최소한 아래를 대조한다.

1. `가져오기검증` 종합결과가 `PASS`인지
2. Raw 총행 수가 483인지
3. 월차/결근/공휴일/수기 건수가 위 기준과 일치하는지
4. 근무일이 실제 Date 형식인지
5. `근태정규화`에서 employee_id 매칭이 예상대로 되는지
6. `근태예외`에 수기·누락·미매칭이 표시되는지
7. 원본 Excel이 수정되지 않았는지
8. 임시 변환 Google Sheet가 휴지통 처리됐는지

## 1회 설치 단계

현재 코드 파일:

`docs/operations/PAYROLL_ATTENDANCE_IMPORT_APPS_SCRIPT.gs`

Google Sheet에 바인딩한 Apps Script 프로젝트에서:

1. 위 코드를 추가한다.
2. `Services`에서 **Drive API**를 추가한다.
3. 스크립트/스프레드시트 시간대는 `Asia/Seoul`을 사용한다.
4. 시트를 다시 연다.
5. `급여 자동화` 메뉴가 생기는지 확인한다.
6. 최초 검증은 **`급여 자동화 > 8월 Golden Import 검사`**를 실행한다. 이 기능은 `설정`의 현재 9월 값을 바꾸지 않고 2026년 8월 원본만 별도로 읽는다.
7. 최초 실행 시 Google 권한 요청을 승인한다.
8. `가져오기검증` 종합결과가 `PASS`인지 확인한다.
9. 검증이 통과한 뒤부터 **`급여 자동화 > 현재월 출퇴근부 가져오기`**를 운영 기능으로 사용한다.

## 승인 경계

이 Import가 통과해도 다음은 자동으로 확정하지 않는다.

- 출퇴근 시각 차이 → 급여시간 환산 규칙
- 주휴수당 계산 의미 변경
- 수기 예외의 급여시간 자동확정
- 실제 급여 월마감/잠금
- 민감 인사정보 외부 공유

이 항목들은 사용자 승인 후 다음 단계에서 처리한다.
