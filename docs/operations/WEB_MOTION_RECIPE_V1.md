# 웹 모션 레시피 V1 — 태장 직원앱 실증

2026-10-17. 범용 프레임워크가 아닌 이번 구현의 이식 안내다. 사용자 최종 수용·실기기 확인은 별도이며 자동 기술 검증을 미학적 성공으로 선언하지 않는다.

## 권장 패턴

1. 글·링크·정적 최종 그림을 먼저 완성한다. 모션을 끄고도 의미가 전달돼야 한다.
2. 한 장면 한 초점. 형태가 변하고 결과로 시선이 넘어가게 한다. 세부 장식의 동시 등장·바운스를 줄인다.
3. 한번 재생하고 멈춘다. 재생 제어는 실제 button, 최소 44px, 키보드 focus 표시. 다시 보기 외에 정적 비교를 제공한다.
4. 정보를 이미 잘 전달하는 기능 목록·이용 안내에는 모션을 넣지 않는다.

## Before/After 카드

- 원본은 HTML 두 `dl`과 독립 기준 문장. 기본은 나란히/모바일 세로 비교.
- JS 준비 후에만 같은 grid 셀에 두 면을 배치해 최대 높이를 확보한다. 앞뒤 모두 DOM·접근성 트리에 유지, 색 이외에 BEFORE/AFTER·한국어 라벨을 둔다.
- 앞면 3200ms 정지, 회전 1000ms, 뒤 180도 고정. WAAPI 전체 easing은 linear, **회전 구간 keyframe에만** `cubic-bezier(.45,0,.2,1)`. 전체 easing에 곡선을 주면 앞면 읽기 시간이 짧아지는 실패가 생긴다.
- fill로 애니메이션 객체를 영구 유지하지 않는다. 종료 CSS 상태를 확정한 뒤 객체를 cancel. 화면 이탈 시 종료하며 재진입 자동 반복 금지.
- `두 내용 함께 보기`는 즉시 정적 배치로 복구. reduced-motion/no-JS/인쇄도 같은 정적 내용. 스크린리더에 뒷면을 aria-hidden 하지 않는다.
- 실제 배포 증거가 없으면 AFTER를 ‘개선 방향’ 또는 ‘디자인 예시’라고 명시한다.

## SVG 형태 전환

대상: `assets/js/employee-app-motion.js`의 HERO render 함수. 승인된 V2.1에서 가져왔다. 같은 점 수의 경로를 시간의 순수 함수로 보간한다. `1-(1-t)^3`는 도착 감속, `t*t*(3-2*t)`는 부드러운 인계. 시작 경로 시계에서 완료 체크로 연결한다. 작은 SVG만 매 프레임 갱신하고 본문·페이지 배치는 바꾸지 않는다.

HERO는 5200ms 유한 재생, 정지/재개/재생 제공. 화면 밖·숨은 탭에서 rAF 중지. 최종 상태는 HTML/CSS에도 있어 컨트롤러 실패 시 내용을 잃지 않는다.

## 브랜드별 바꿀 항목

기존 CSS 변수의 색·본문/제목 글꼴·선 두께·여백·모서리부터 맞춘다. SVG 경로는 콘텐츠에 맞춰 별도 설계한다. 태장 회사 문구·직원 의견·날짜·업무 기능·연락처·운영 주소를 다른 사이트로 복제하지 않는다. 이식 대상에 검증된 최소 HTML/CSS/JS만 복사하고 태장 런타임에 의존하지 않는다.

## QA와 이식 순서

정적 HTML → 양면 비교 → 모바일 재배치 → 단일 모션 → 실제 재생/중간 프레임/최종 프레임 확인 → 필요 부분만 보강한다. 테스트 helper를 같은 계약에 맞게 적응한다.

- 1440/1120/1001/768/720/390/360/320px: 가로 넘침, 본문 잘림, 읽기 순서, 링크 유지.
- 200% 글자와 400%에 대응하는 CSS reflow. 실 브라우저 확대 및 Android/iOS는 별도로 구분.
- JS off, 컨트롤러 실패, reduced-motion 최초/실시간 변경, 인쇄, 키보드, 접근성 트리 양면 텍스트.
- 회전 전/중/후 카드 외곽 좌표 일치, 재진입 반복 없음, 종료 애니메이션 없음, hidden 탭 정지.
- 외부 의존성·요청 추가 여부, 전용 JS/CSS 바이트 수, rAF/CLS 실제 표본. 데스크톱 headless 수치를 휴대폰 FPS·배터리로 부르지 않는다.
- 로딩 검사는 networkidle 하나에 의존하지 않는다. 제품 리소스·글꼴·표시·배치 안정과 실패 trace를 확인한다.

좋은 예: 직원 불편과 개선 방향이 같은 위치에서 바뀌고 중요한 기준은 그대로 남는 카드. 실패 예: 세 카드 반복 등장, 필수 단계로 오해되는 점선, 앞면을 읽기도 전에 회전, 360도·무한반복, 사진처럼 보이는 가짜 앱 화면, JS 실패 시 빈 콘텐츠.
