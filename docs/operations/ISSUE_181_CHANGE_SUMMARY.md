# Issue #181 변경 요약

## 홍보팀장 관리 UX

- `홍보 검토`를 홍보팀장 화면에서 `홍보 관리`로 통합 표기
- 홍보팀장 사이드바의 별도 archive/글관리 중복 진입점 숨김
- 검토 카드에 기존 `직접 수정`과 함께 recoverable `삭제` 추가
- 승인 완료·미발행 글을 같은 홍보 관리 화면 아래에 표시하고 삭제 가능
- 삭제 사유 필수, hard delete 없음, revision/audit 보존, 운영총괄 복구 유지
- 공개 이력이 있는 글의 기존 숨김/재공개/삭제요청 정책 유지

## GPS

- 6초 샘플 시점의 부정확한 위치를 조기 확정하지 않음
- 80m 이내 정확도는 즉시 성공
- 그렇지 않으면 최종 14초 제한까지 더 좋은 위치를 계속 수집
- 최종 제한시간에는 best fix를 기존 서버에 전달하여 서버의 정확도/60m geofence 판정을 유지

## 외부 링크 불러오기

- 기존 한 버튼에 붙어 있던 metadata/body 두 요청을 캡처 단계의 단일 요청으로 통합
- 비어 있는 제목/요약/본문/대표이미지만 자동 채움
- 직접 입력 내용은 덮어쓰지 않음
- 실패해도 수동 입력 및 저장·승인요청 가능 안내
- 외부 metadata function의 보안/쿼터 계약은 변경하지 않음

## 테스트

- 홍보팀장 통합 관리 UX static contract 테스트 보강
- GPS 6초 경계 후 정확도 개선 시나리오 테스트 추가
- 최종 timeout best-fix 전달 테스트 추가
- 링크 단일 fetch / manual fallback 계약 테스트 추가

CI와 Deploy Preview 결과는 Draft PR에서 확인한다.
