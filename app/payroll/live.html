1. 확정 근태 확인

급여 계산 준비상태

운영팀장이 일일 확정한 근태만 정상 급여 계산 입력으로 사용합니다.

확정 근태 상태를 불러오는 중입니다.

미확정 날짜와 예외를 확인합니다.

    업무플랫폼에서 출근부 확인
    비상·과거자료 보조입력 열기 · 현재 확정근태 기반 급여 계산의 정상 입력경로가 아닙니다.

    보조 기능

    과거·비상 근태 입력

    과거자료 보완이나 비상 대응이 필요할 때만 사용합니다. 현재 급여 가안은 운영팀장이 확정한 근태 Gate를 통과해야 계산됩니다.

    Excel 선택 안 함 · 비상/과거자료 보조입력 Excel은 보조수단입니다. 선택하면 시트·헤더·행 수를 먼저 확인하고 과거·비상 입력표에 채웁니다.

    근태 입력표 불러오는 중

    사번 성명 상태 출근 퇴근 인정시간 출처

    저장하면 원본을 덮어쓰지 않고 보조 변경이력으로 남깁니다. 정상 급여 계산은 위의 확정 근태 준비상태를 사용합니다.

    2. 급여 확인

    월 급여대장

    i
    이 급여월은 아직 계산결과가 없습니다.

    위의 확정 근태로 급여 가안 계산을 실행하면 이곳에 직원별 급여대장이 표시되고, 각 직원 행 오른쪽 명세서 초안 버튼에서 개인 명세서를 확인할 수 있습니다.

    사번 성명 입사일 퇴사일 실근로 결근 유급휴가 유급공휴일 주휴시간 기본급 주휴수당 총지급 국민연금 건강보험 장기요양 고용보험 공제계 실지급 상태 개인 초안

    사용 상태

    근태 기준일
    —
    계산 Run

    계산 버전
    —
    • 운영총괄은 운영팀장이 확정한 근태의 준비상태를 확인한 뒤 급여 가안을 계산합니다.
    • 급여 확정·월 잠금·송금 기능은 없습니다.
    • 직접입력·Excel은 과거자료 또는 비상 대응용 보조수단이며 정상 급여 계산 입력은 확정근태입니다.
    • Excel 원본과 기존 근태 원본은 덮어쓰지 않고, 화면 수정은 별도 변경이력으로 남깁니다.
    • 주민등록번호·급여계좌·장애·건강정보는 화면/가안 Excel에 넣지 않습니다.
    • 급여대장은 직원 중복·계산 인원·총지급-공제-실지급 산식을 자동 검증합니다.
    • 구형 XLS는 실제 보안업체 원본을 확인한 뒤 전용 지원 여부를 결정합니다.
    • 모바일 최적화는 PC 사전운영 안정화 후 이어서 적용합니다.
    • 현재 급여 플로의 법정공제 범위는 국민연금·건강보험·장기요양·고용보험까지입니다.
    • 법정공제 근거가 부족한 직원은 금액을 추정하지 않고 확인 필요로 표시합니다.

    운영총괄 PC 사전운영 근태·급여 화면입니다. 실제 급여 확정·지급을 실행하지 않으며 Production 급여월을 변경하지 않습니다.
