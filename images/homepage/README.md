# 홈페이지 공개용 이미지 폴더

이 폴더에는 **공개 승인이 끝난 홈페이지용 변환본만** 저장합니다.

원본 사진, 공개동의서, 동의 관리대장, 사용 금지 사진은 이 저장소에 넣지 않습니다. 원본과 동의 자료는 접근 권한이 제한된 공유 드라이브에서 별도로 관리합니다.

## 현재 운영 방식

과거에는 PHOTO 01~08을 모두 `photo-NN.webp`와 1:1로 연결했지만, 현재 공개 홈페이지는 Hero 영상과 페이지별 승인 이미지가 추가되어 일부 식별자가 다른 공개 자산을 사용합니다.

PHOTO 번호는 편집·검수용 식별자이며, **현재 공개 HTML에 명시된 승인 이미지가 우선**합니다.

`assets/js/photo-slots.js`는 정적 `<img>`가 이미 있으면 그 이미지를 교체하지 않습니다. 따라서 페이지별로 승인된 파생 이미지나 최신 현장사진을 정적 HTML에서 사용할 수 있습니다.

## 최신 소식 이미지

메인 최근 활동과 `archive.html`의 최신 소식 카드는 각 콘텐츠의 `thumbnail`과 `thumbnailAlt`를 사용합니다. 메인 최신 최대 8개 카드는 고정 PHOTO 번호가 아니라 각 게시물의 대표사진을 사용합니다.

PHOTO 09~11 번호를 최신 소식용 고정 파일명으로 사용하지 않습니다.

## 사진 교체 순서

1. 실제 페이지에서 현재 어떤 자산을 쓰는지 먼저 확인합니다.
2. 공개 승인된 최종 사진을 WebP로 변환합니다.
3. 기존 고정 경로를 교체하는 경우 파일 용량과 이미지 budget을 확인합니다.
4. PC와 모바일 crop을 확인하고 필요한 경우 `objectPosition` / `mobileObjectPosition`을 조정합니다.
5. 사진 내용과 alt가 정확히 일치하는지 확인합니다.
6. 여러 페이지가 같은 사진을 재사용하면 모든 위치를 함께 검수합니다.
7. `PHOTO_REVIEW_MODE`를 사용할 경우 Preview 검수 뒤 공개 모드로 되돌립니다.

## PHOTO 04~06 재촬영 기준

현재 PHOTO 04~06은 모두 포장 작업과 유사해 역할이 겹칩니다. 새 촬영에서는 다음처럼 장면을 구분합니다.

- PHOTO 04: 직원 2명 안팎이 함께 일하는 전체 작업 현장
- PHOTO 05: 직원 1명이 검수·분류·조립·포장 등 한 단계에 집중하는 장면
- PHOTO 06: 직원과 담당자 또는 직원 2명이 작업물·작업순서·체크리스트를 함께 확인하는 장면

새 사진은 공개 승인 확인 전 저장소에 추가하지 않습니다.

## 주의

- `photo-01.webp`, `photo-03.webp`, `photo-09.webp`~`photo-11.webp` 등 현재 미사용 자산도 사용자 승인 없이 삭제하지 않습니다.
- 현재 공개 화면을 단순 번호 규칙에 맞추기 위해 과거 이미지로 되돌리지 않습니다.
- 파일명에는 직원 이름, 장애정보, 건강정보 등 민감정보를 넣지 않습니다.
