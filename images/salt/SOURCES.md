# 뉴질랜드 천일염 이미지 출처

2026-11-09 사용자가 Dominion Salt 본사와의 협력 관계와 동일 상품임을 설명하고 본사 자료·사진의 태장 페이지 활용을 허용했다. 같은 날 사용자는 (주)뉴질랜드솔트 제품 브로셔 수록 사진의 사용 허락도 받았다고 알렸다. 서면 허락 자료는 사용자가 보관하며 이 저장소에는 올리지 않는다. 공개 전 사용 범위와 출처 표기 조건을 한 번 더 확인한다.
